    Раздел 9.3 Определители

    Подраздел 9.3.1 Определение определителя

    Следующее определение приведет нас к чистому, красивому, не зависящему от базиса определению определителя оператора.
    🔗

    Определение 9.40 \(\alpha_T\).

    Предположим, что \(m\) — целое положительное число и \(T \in \Lc(V)\). Для \(\alpha \in V_{\text{ alt } }^{(m)}{}\) определите \(\alpha_T \in V^{(m)}_{\text{ alt } }\) как
    \begin{equation*} \alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) \end{equation*}
    для каждого списка \(v_1, \ldots, v_m\) векторов из \(V{}\).
    🔗
    🔗
    Предположим, \(T \in \Lc(V)\). Если \(\alpha \in V^{(m)}_{\text{ alt } }\) и \(v_1, \ldots, v_m\) — список векторов из \(V\), причем \(v_j = v_k\) для некоторого \(j \ne k\), то \(Tv_j = Tv_k\), откуда следует, что \(\alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) = 0\). Таким образом, функция \(\alpha \mapsto \alpha_T\) является линейным отображением \(V^{(m)}_{\text{ alt } }\) в себя.
    🔗
    Мы знаем, что \(\dim V^{(\dim V)}_{\text{ alt } } = 1\) (см. Теорему 9.37). Каждое линейное отображение одномерного векторного пространства в себя есть умножение на некоторый единственный скаляр. Для линейного отображения \(\alpha \mapsto \alpha_T\) мы теперь определяем \(\det T\) как этот скаляр.
    🔗

    Определение 9.41 определитель оператора, \(\det T\).

    Предположим, \(T \in \Lc(V)\). Определитель числа \(T{}\), обозначаемый \(\det T{}\), определяется как единственное число в \(\F{}\) такое, что
    \begin{equation*} \alpha_T = (\det T) \alpha \end{equation*}
    для всех \(\alpha \in V_{\text{ alt } }^{(\dim V)}{}\).
    🔗
    🔗
    🔗

    Пример 9.42 определители операторов.

    Пусть \(n = \dim V{}\).
    1. Если \(I\) — тождественный оператор на \(V{}\), то \(\alpha_I = \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Таким образом, \(\det I = 1\).
      🔗
      🔗
    2. В более общем смысле, если \(\lambda \in \F{}{}\), то \(\alpha_{\lambda I} = \lambda^n \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Таким образом, \(\det (\lambda I )= \lambda^n{}\).
      🔗
      🔗
    3. В более общем смысле, если \(T \in \Lc(V)\) и \(\lambda \in \F{}{}\), то \(\alpha_{\lambda T} = \lambda^n \alpha_T = \lambda^n (\det T) \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Таким образом, \(\det (\lambda T) = \lambda^n \det T{}\).
      🔗
      🔗
    4. Предположим, \(T \in \Lc(V)\) и существует базис \(e_1, \ldots, e_n\) матрицы \(V\), состоящий из собственных векторов \(T{}\) с соответствующими собственными значениями \(\lambda_1, \ldots, \lambda_n\). Если \(\alpha \in V_{\text{ alt } }^{(n)}{}\), то
      \begin{equation*} \alpha_T(e_1, \ldots, e_n) = \alpha (\lambda_1 e_1, \ldots, \lambda_n e_n) = (\lambda_1 \cdots \lambda_n) \alpha (e_1, \ldots, e_n). \end{equation*}
      Если \(\alpha \ne 0\), то из Теоремы 9.39 следует \(\alpha (e_1, \ldots, e_n) \ne 0\). Таким образом, из приведенного выше уравнения следует
      \begin{equation*} \det T = \lambda_1 \cdots \lambda_n. \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Наша следующая задача — определить и дать формулу определителя квадратной матрицы. Для этого мы связываем с каждой квадратной матрицей оператор, а затем определяем определитель матрицы как определитель соответствующего оператора.
    🔗

    Определение 9.43 определитель матрицы, \(\det A\).

    Предположим, что \(n\) — целое положительное число, а \(A\) — квадратная матрица размером \(n\) на \(n\) с элементами из \(\F{}{}\). Пусть \(T \in \Lc( \F n )\) — оператор, матрица которого относительно стандартного базиса \(\F n\) равна \(A\). Определитель \(A\), обозначаемый \(\det A\), определяется \(\det A = \det T{}\).
    🔗
    🔗
    🔗

    Пример 9.44 определители матриц.

    1. Если \(I\) — единичная матрица размера \(n\) на \(n\), то соответствующий оператор на \(\F n\) — это единичный оператор \(I\) на \(\FF n\). Таким образом, первый пункт Примера 9.42 подразумевает, что определителем единичной матрицы является \(1\).
      🔗
      🔗
    2. Предположим, что \(A\) — диагональная матрица, на диагонали которой находится \(\lambda_1, \ldots, \lambda_n\). Тогда соответствующий оператор на \(\F n\) имеет стандартный базис \(\F n\) в виде собственных векторов с собственными значениями \(\lambda_1, \ldots, \lambda_n\). Таким образом, последний пункт Примера 9.42 подразумевает, что \(\det A = \lambda_1 \cdots \lambda_n\).
      🔗
      🔗
    🔗
    🔗
    Для следующего результата подумайте о каждом списке \(v_1, \ldots, v_n\) векторов \(n\) в \(\F n\) как о списке векторов-столбцов \(n\) на \(1\). Обозначение \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) тогда обозначает квадратную матрицу размером \(n\) на \(n\), столбец \(k^\nth\) которой равен \(v_k\) для каждого \(k = 1, \ldots, n\).
    🔗

    Теорема 9.45 Определитель представляет собой знакопеременную полилинейную форму.

    Предположим, что \(n\) — целое положительное число. Отображение, которое переводит список \(v_1, \ldots, v_n\) векторов из \(\F n\) в \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\), представляет собой знакопеременную \(n\)-линейную форму на \(\FF n\).
    🔗
    🔗

    Доказательство.
    Пусть \(e_1, \ldots, e_n\) — стандартный базис \(\FF n\) и \(v_1, \ldots, v_n\) — список векторов из \(\FF n\). Пусть \(T \in \Lc( \F n )\) — оператор такой, что \(Te_k = v_k\) для \(k = 1, \ldots, n\). Таким образом, \(T\) — это оператор, матрица которого относительно \(e_1, \ldots, e_n\) равна \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\). Следовательно, \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} = \det T{}\) по определению определителя матрицы.
    🔗
    Пусть \(\alpha\) — знакопеременная \(n\)-линейная форма на \(\F n\) такая, что \(\alpha (e_1, \ldots, e_n) = 1\). Тогда
    \begin{align*} \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} \amp = \det T\\ \amp = (\det T) \alpha (e_1, \ldots, e_n)\\ \amp =\alpha (Te_1, \ldots, Te_n)\\ \amp = \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
    где третья строка следует из определения определителя оператора. Уравнение выше показывает, что отображение, которое переводит список векторов \(v_1, \ldots, v_n\) из \(\F n\) в \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\), представляет собой знакопеременную \(n\)-линейную форму \(\alpha\) на \(\FF n\).
    🔗
    🔗
    Предыдущий результат имеет несколько важных следствий. Например, из этого сразу следует, что матрица с двумя одинаковыми столбцами имеет определитель \(0\). К другим следствиям мы еще вернемся, а пока хотим привести формулу определителя квадратной матрицы. Напомним, что если \(A\) — матрица, то \(A_{j,k}\) обозначает элемент в строке \(j\), столбце \(k\) матрицы \(A\).
    🔗

    Теорема 9.46 формула определителя матрицы.

    Предположим, что \(n\) — целое положительное число, а \(A\) — квадратная матрица размером \(n\) на \(n\). Тогда
    \begin{equation*} \det A = \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) A_{j_1,1} \cdots A_{j_n,n}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Примените Теорему 9.36, где \(V = \F n\) и \(e_1, \ldots, e_n\) являются стандартным базисом \(\F n\), а \(\alpha\) - знакопеременной \(n\)-линейной формой на \(\F n\), которая переводит \(v_1, \ldots, v_n\) в \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) [см. Теорему 9.45]. Если каждый \(v_k\) является столбцом \(k^\nth\) столбца \(A\), то каждый \(b_{j,k}\) в Теореме 9.36 равен \(A_{j,k}\). Наконец,
    \begin{equation*} \alpha (e_1, \ldots, e_n) = \det \begin{pmatrix}e_1 \amp \cdots \amp e_n \end{pmatrix} = \det I = 1. \end{equation*}
    🔗
    Таким образом, формула в Теореме 9.36 становится формулой, изложенной в этом результате.
    🔗
    🔗

    Пример 9.47 явная формула определителя.

    1. Если \(A\) представляет собой матрицу \(2\) на \(2\), то формула в Теореме 9.46 принимает вид
      \begin{equation*} \det A = A_{1,1} A_{2,2} - A_{2,1} A_{1,2}. \end{equation*}
      🔗
      🔗
    2. Если \(A\) представляет собой матрицу \(3\) на \(3\), то формула в Теореме 9.46 принимает вид
      \begin{align*} \det A = \amp A_{1,1} A_{2,2} A_{3,3} - A_{2,1} A_{1,2} A_{3,3} - A_{3,1} A_{2,2} A_{1,3}\\ \amp {}- A_{1,1} A_{3,2} A_{2,3} + A_{3,1} A_{1,2} A_{2,3} + A_{2,1} A_{3,2} A_{1,3}\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    Сумма в формуле Теоремы 9.46 содержит \(n!\) членов. Поскольку \(n!\) быстро растет по мере увеличения \(n\), формула в теореме 9.46 не является жизнеспособным методом оценки детерминантов даже для \(n\) среднего размера. Например, \(10!\) превышает три миллиона, а \(100!\) примерно равен \(10^{158}\), что приводит к сумме, которую не может оценить даже самый быстрый компьютер. Вскоре мы увидим некоторые результаты, которые приведут к более быстрому вычислению определителей, чем прямое использование суммы в теореме 9.46.
    🔗

    Теорема 9.48 определитель верхнетреугольной матрицы.

    Предположим, что \(A\) — верхнетреугольная матрица с \(\lambda_1, \ldots, \lambda_n\) на диагонали. Потом \(\det A = \lambda_1 \cdots \lambda_n\).
    🔗
    🔗

    Доказательство.
    Если \((j_1, \ldots, j_n) \in \perm n\) с \((j_1, \ldots, j_n) \ne (1, \ldots, n)\), то \(j_k > k\) для некоторого \(k \in \{ 1, \ldots, n \}\), откуда следует, что \(A_{j_k, k} = 0\). Таким образом, единственная перестановка, которая может внести ненулевой вклад в сумму в Теореме 9.46, — это перестановка \((1, \ldots, n)\). Поскольку \(A_{k, k} = \lambda_k\) для каждого \(k = 1, \ldots, n\), это означает, что \(\det A = \lambda_1 \cdots \lambda_n\).
    🔗
    🔗
    🔗

    Подраздел 9.3.2 Свойства определителей

    Наше определение определителя приводит к следующему волшебному доказательству того, что определитель мультипликативен.
    🔗

    Теорема 9.49 определитель мультипликативен.

    1. Предположим, \(S, T \in \Lc(V)\). Потом \(\det (ST) = (\det S)(\det T)\).
      🔗
      🔗
    2. Предположим, \(A\) и \(B\) — квадратные матрицы одного размера. Тогда
      \begin{equation*} \det (AB) = (\det A)(\det B) \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    1. Пусть \(n = \dim V{}\). Предположим \(\alpha \in V^{(n)}_{\text{ alt } }\) и \(v_1, \ldots, v_n \in V{}\). Тогда
      \begin{align*} \alpha_{ST} (v_1, \ldots, v_n) \amp = \alpha ( STv_1, \ldots, STv_n)\\ \amp = (\det S) \alpha (Tv_1, \ldots, Tv_n)\\ \amp = (\det S)(\det T) \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
      где первое уравнение следует из определения \(\alpha_{ST}\), второе уравнение следует из определения \(\det S\), а третье уравнение следует из определения \(\det T{}\). Из приведенного выше уравнения следует, что \(\det (ST) = (\det S)(\det T)\).
      🔗
      🔗
    2. Пусть \(S, T \in \Lc( \F n )\) таков, что \(\M(S) = A\) и \(\M(T) = B\), где все матрицы операторов в этом доказательстве относятся к стандартному базису \(\FF n\). Тогда \(\M(ST) = \M(S) \M(T) = AB\) (см. Теорема 3.43). Таким образом
      \begin{equation*} \det(AB) = \det(ST) = (\det S)(\det T) = (\det A)(\det B), \end{equation*}
      где второе равенство получается из результата в (a).
      🔗
      🔗
    🔗
    🔗
    Определитель оператора определяет, является ли оператор обратимым.
    🔗

    Теорема 9.50 обратимость \(\iff\) ненулевой определитель.

    Оператор \(T \in \Lc(V)\) обратим тогда и только тогда, когда \(\det T \ne 0\). Более того, если \(T\) обратима, то \(\det ( T^{-1} ) = \frac{1}{\det T}\).
    🔗
    🔗

    Доказательство.
    Предположим сначала, что \(T\) обратимо. Таким образом \(T T^{-1} = I\). Теперь из Теоремы 9.49 следует, что
    \begin{equation*} 1 = \det I = \det ( TT^{-1} ) = (\det T) ( \det ( T^{-1} ) ). \end{equation*}
    🔗
    Следовательно, \(\det T \ne 0\) и \(\det ( T^{-1} )\) являются обратным элементом \(\det T{}\).
    🔗
    Чтобы доказать обратное, предположим теперь, что \(\det T \ne 0\). Предположим \(v \in V\) и \(v \ne 0\). Пусть \(v, e_2, \ldots, e_n\) — базис \(V\) и пусть \(\alpha \in V^{(n)}_{\text{ alt } }\) таков, что \(\alpha \ne 0\). Тогда \(\alpha (v, e_2, \ldots, e_n) \ne 0\) (по теореме 9.39). Сейчас
    \begin{equation*} \alpha (Tv, Te_2, \ldots, Te_n) = (\det T) \alpha (v, e_2, \ldots, e_n) \ne 0. \end{equation*}
    🔗
    Таким образом, \(Tv \ne 0\). Следовательно, \(T\) обратима.
    🔗
    🔗
    Матрица \(A\) размером \(n\) на \(n\) является обратимой (см. Определение 3.80 для определения обратимой матрицы) тогда и только тогда, когда оператор на \(\F n\), связанный с \(A\) (через стандартный базис \(\F n\)), является обратимым. Таким образом, предыдущий результат показывает, что квадратная матрица \(A\) обратима тогда и только тогда, когда \(\det A \ne 0\).
    🔗

    Теорема 9.51 собственные значения и определители.

    Предположим \(T \in \Lc(V)\) и \(\lambda \in \F{}{}\). Тогда \(\lambda\) является собственным значением \(T\) тогда и только тогда, когда \(\det(\lambda I - T) = 0\).
    🔗
    🔗

    Доказательство.
    Число \(\lambda\) является собственным значением \(T\) тогда и только тогда, когда \(T - \lambda I\) не обратимо (см. Теорему 5.7), что происходит тогда и только тогда, когда \(\lambda I - T\) не обратимо, что происходит тогда и только тогда, когда \(\det(\lambda I - T) = 0\) (по Теореме 9.50).
    🔗
    🔗
    Предположим, что \(T \in \Lc(V)\) и \(\fun S W V\) — обратимое линейное отображение. Чтобы доказать, что \(\det( S^{-1} T S ) = \det T\), мы могли бы попытаться использовать Теорему 9.49 и Теорему 9.50, написав
    \begin{align*} \det( S^{-1} T S )\amp = ( \det S^{-1} ) (\det T) (\det S)\\ \amp = \det T{}\text{.} \end{align*}
    🔗
    Это доказательство работает, если \(W = V{}\), но если \(W \ne V\), то оно не имеет смысла, поскольку определитель определен только для линейных отображений векторного пространства в себя, а \(S\) отображает \(W\) в \(V{}\), делая \(\det S\) неопределенным. Доказательство, приведенное ниже, решает эту проблему и справедливо, когда \(W \ne V{}\).
    🔗

    Теорема 9.52 Определитель является инвариантом подобия.

    Предположим, что \(T \in \Lc(V)\) и \(\fun S W V\) — обратимое линейное отображение. Тогда
    \begin{equation*} \det( S^{-1} T S ) = \det T{}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(n = \dim W = \dim V{}\). Предположим \(\tau \in W_{\text{ alt } }^{(n)}{}\). Определите \(\alpha \in V^{(n)}_{\text{ alt } }\) по
    \begin{equation*} \alpha (v_1, \ldots, v_n) = \tau( S^{-1}v_1, \ldots, S^{-1}v_n ) \end{equation*}
    для \(v_1, \ldots, v_n \in V{}\). Предположим \(w_1, \ldots, w_n \in W{}\). Тогда
    \begin{align*} \tau_{S^{-1} T S}( w_1, \ldots, w_n) \amp = \tau( S^{-1}TS w_1, \ldots, S^{-1} T S w_n )\\ \amp = \alpha ( TSw_1, \ldots, TSw_n)\\ \amp = \alpha_T( Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \alpha (Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \tau(w_1, \ldots, w_n)\text{.} \end{align*}
    🔗
    Из приведенного выше уравнения и определения определителя оператора \(S^{-1} T S\) следует, что \(\det( S^{-1} T S ) = \det T{}\).
    🔗
    🔗
    Для частного случая, когда \(V = \F n\) и \(e_1, \ldots, e_n\) являются стандартным базисом \(\FF n\), следующий результат верен по определению определителя матрицы. Левая часть уравнения в следующем результате не зависит от выбора базиса, а это означает, что правая часть не зависит от выбора базиса.
    🔗

    Теорема 9.53 определитель оператора равен определителю его матрицы.

    Предположим, \(T \in \Lc(V)\) и \(e_1, \ldots, e_n\) — базис \(V{}\). Тогда
    \begin{equation*} \det T = \det \M( T, (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(f_1, \ldots, f_n\) — стандартный базис \(\FF{n}\). Пусть \(\fun S {\F n} V\) — линейное отображение такое, что \(Sf_k = e_k\) для каждого \(k = 1, \ldots, n\). Таким образом, \(\M( S, (f_1, \ldots, f_n), (e_1, \ldots, e_n) )\) и \(\M( S^{-1} , (e_1, \ldots, e_n), (f_1, \ldots, f_n) )\) равны единичной матрице \(n\) на \(n\). Следовательно
    \begin{equation} \M( S^{-1} T S, (f_1, \ldots, f_n) ) = \M( T, (e_1, \ldots, e_n) ),\tag{9.54} \end{equation}
    как следует из двух приложений теоремы 3.43. Таким образом
    \begin{align*} \det T \amp = \det( S^{-1} T S )\\ \amp = \det \M( S^{-1} T S, (f_1, \ldots, f_n) )\\ \amp = \det \M( T, (e_1, \ldots, e_n) )\text{,} \end{align*}
    где первая строка взята из Теоремы 9.52, вторая строка — из определения определителя матрицы, а третья строка — из (9.54).
    🔗
    🔗
    Следующий результат дает более интуитивный способ рассмотрения детерминантов, чем определение или формула в теореме 9.46. Мы могли бы дать характеристику в результате ниже определения определителя оператора в конечномерном комплексном векторном пространстве, при этом текущее определение станет следствием этого определения.
    🔗

    Теорема 9.55 если \(\F{} = \C{}\), то определитель равен произведению собственных значений.

    Предположим \(\F{} = \C{}\) и \(T \in \Lc(V)\). Тогда \(\det T\) равно произведению собственных значений \(T{}\), причем каждое собственное значение включено столько раз, сколько его кратность.
    🔗
    🔗

    Доказательство.
    Существует базис \(V\), по отношению к которому \(T\) имеет верхнетреугольную матрицу, диагональные элементы которой состоят из собственных значений \(T{}\), причем каждое собственное значение включено столько раз, сколько его кратность — см. Теорема 8.37. Таким образом, Теорема 9.53 и Теорема 9.48 подразумевают, что \(\det T\) равно произведению собственных значений \(T{}\), причем каждое собственное значение включено столько раз, сколько его кратность.
    🔗
    🔗
    Как показывает следующий результат, определитель прекрасно взаимодействует с транспонированием квадратной матрицы, с двойственным оператором и с сопряженным оператором в пространстве со скалярным произведением.
    🔗

    Теорема 9.56 определитель транспонированной матрицы, двойственного или сопряжённого оператора.

    1. Предположим, \(A\) — квадратная матрица. Потом \(\det \tran{A} = \det A\).
      🔗
      🔗
    2. Предположим, \(T \in \Lc(V)\). Потом \(\det T' = \det T{}\).
      🔗
      🔗
    3. Предположим, что \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Тогда
      \begin{equation*} \det ( T^* ) = \overline{\det T}{}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    1. Пусть \(n\) — целое положительное число. Определите \(\fun \alpha { ( \F n )^n} {\F{}}\) по
      \begin{equation*} \alpha ( v_1, \ldots, v_n ) = \det ( \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } ) \end{equation*}
      для всех \(v_1, \ldots, v_n \in \FF n\). Формула в Теореме 9.46 для определителя матрицы показывает, что \(\alpha\) является \(n\)-линейной формой на \(\FF n\). Предположим, \(v_1, \ldots, v_n \in \F n\) и \(v_j = v_k\) для некоторого \(j \ne k\). Если \(B\) является матрицей \(n\) на \(n\), то \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }B\) не может равняться единичной матрице, поскольку строка \(j\) и строка \(k\) матрицы \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } B\) равны. Таким образом, \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }\) не является обратимым, а это означает, что \(\alpha ( v_1, \ldots, v_n ) = 0\). Следовательно, \(\alpha\) — знакопеременная \(n\)-линейная форма на \(\FF n\). Обратите внимание, что \(\alpha\), примененная к стандартному базису \(\F n\), равна \(1\). Поскольку векторное пространство знакопеременных \(n\)-линейных форм на \(\F n\) имеет размерность единица (по теореме 9.37), это означает, что \(\alpha\) является детерминантной функцией. Таким образом, (а) имеет место.
      🔗
      🔗
    2. Уравнение \(\det T' = \det T{}\) следует из (a), а также теоремы 9.53 и теоремы 3.132.
      🔗
      🔗
    3. Выберите ортонормированный базис \(V{}\). Матрица \(T^*\) относительно этого базиса представляет собой сопряженное транспонирование матрицы \(T\) относительно этого базиса (согласно Теореме 7.9). Таким образом, из Теоремы 9.53, Теоремы 9.46 и (a) следует, что \(\det ( T^* ) = \overline{\det T}{}\).
      🔗
      🔗
    🔗

    Теорема 9.57 полезные результаты при оценке детерминантов.

    1. Если два столбца или две строки квадратной матрицы равны, то определитель матрицы равен \(0\).
      🔗
      🔗
    2. Предположим, \(A\) — квадратная матрица, а \(B\) — матрица, полученная из \(A\) заменой двух столбцов или двух строк. Потом \(\det A = - \det B\).
      🔗
      🔗
    3. Если один столбец или одна строка квадратной матрицы умножается на скаляр, то значение определителя умножается на тот же скаляр.
      🔗
      🔗
    4. Если к другому столбцу добавить скаляр, кратный одному столбцу квадратной матрицы, то значение определителя не изменится.
      🔗
      🔗
    5. Если к другой строке прибавить скаляр, кратный одной строке квадратной матрицы, то значение определителя не изменится.
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    Все утверждения этого результата следуют из того, что отображения \(v_1, \ldots, v_n \mapsto \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) и \(v_1, \ldots, v_n \mapsto \det \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }\) являются знакопеременными \(n\)-линейными формами на \(\FF n\) [см. Теорему 9.45 и Теорему 9.56(a)].
    🔗
    Например, чтобы доказать (d), предположим, что \(v_1, \ldots, v_n \in \F n\) и \(c \in \F{}{}\). Тогда
    \begin{align*} \det \amp \begin{pmatrix}v_1 + cv_2 \amp v_2 \amp \cdots \amp v_n \end{pmatrix}\\ \amp =\det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} + c\det \begin{pmatrix}v_2 \amp v_2 \amp v_3 \amp \cdots \amp v_n \end{pmatrix}\\ \amp = \det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} \text{,} \end{align*}
    где первое уравнение следует из свойства полилинейности, а второе уравнение — из свойства знакопеременности. Приведенное выше уравнение показывает, что добавление числа, кратного второму столбцу, к первому столбцу не меняет значения определителя. Тот же вывод справедлив для любых двух столбцов. Таким образом, (d) имеет место.
    🔗
    Доказательство (e) следует из (d) и теоремы 9.56(a). Доказательства (a), (b) и (c) используют аналогичные инструменты и предоставляются читателю.
    🔗
    🔗
    Для матриц, элементами которых являются конкретные числа, приведенный выше результат позволяет гораздо быстрее вычислить определитель, чем прямое применение формулы из теоремы 9.46. В частности, примените процедуру исключения Гаусса для замены строк [по Теореме 9.57(b), это изменит определитель в \(-1\) раз] , умножив строку на ненулевую константу [по Теореме 9.57(c), это изменит определитель на ту же константу] и добавив кратное число одной строки к другой строке [по Теорема 9.57(e), это не меняет определитель] для создания верхнетреугольной матрицы, определитель которой является произведением диагональных элементов (по Теореме 9.48). Если ваше программное обеспечение отслеживает количество перестановок строк и константы, используемые при умножении строки на константу, то можно вычислить определитель исходной матрицы.
    🔗
    Поскольку число \(\lambda \in \F{}\) является собственным значением оператора \(T \in \Lc(V)\) тогда и только тогда, когда \(\det(\lambda I - T) = 0\) (согласно Теореме 9.51), у вас может возникнуть соблазн подумать, что один из способов быстро найти собственные значения — это выбрать базис \(V{}\), позволить \(A = \M(T)\), вычислить \(\det(\lambda I - A)\), а затем решить уравнение \(\det(\lambda I - A) = 0\) для \(\lambda\). Однако эта процедура редко бывает эффективной, за исключением случаев, когда \(\dim V = 2\) (или когда \(\dim V\) равно \(3\) или \(4\), если вы готовы использовать кубические или четвертые формулы). Одна из проблем заключается в том, что описанная в предыдущем абзаце процедура вычисления определителя не работает, когда матрица содержит символ (например, \(\lambda\) в \(\lambda I - A\)). Эта проблема возникает потому, что в процедуре исключения Гаусса необходимо принять решения о том, равны ли определенные величины \(0\), и эти решения усложняются в выражениях, включающих символ \(\lambda\).
    🔗
    Напомним, что оператор в конечномерном пространстве со скалярным произведением является унитарным, если он сохраняет нормы (см. Определение 7.51 и следующий за ним абзац). Каждое собственное значение унитарного оператора имеет абсолютное значение \(1\) (по теореме 7.54). Таким образом, произведение собственных значений унитарного оператора имеет абсолютное значение \(1\). Следовательно (по крайней мере в случае \(\F{} = \C{}\)) определитель унитарного оператора имеет абсолютное значение \(1\) (по теореме 9.55). Следующий результат дает доказательство, работающее без предположения, что \(\F{} = \C{}\).
    🔗

    Теорема 9.58 определитель любого унитарного оператора по модулю равен \(1\).

    Предположим, что \(V\) — пространство со скалярным произведением, а \(S \in \Lc(V)\) — унитарный оператор. Потом \(\lvert \det S \rvert = 1\).
    🔗
    🔗
    🔗

    Доказательство.
    Поскольку \(S\) унитарно, \(I = S^* S\) (см. Теорему 7.53). Таким образом
    \begin{equation*} 1 = \det(S^* S) = (\det S^*) (\det S) = \overline{( \det S)} (\det S) = \lvert \det S \rvert ^2{}, \end{equation*}
    где второе равенство вытекает из Теоремы 9.49(a), а третье равенство вытекает из Теоремы 9.56(c). Из приведенного выше уравнения следует, что \(\lvert \det S \rvert = 1\).
    🔗
    🔗
    Определитель положительного оператора в пространстве со скалярным произведением хорошо согласуется с аналогией, согласно которой такие операторы соответствуют неотрицательным действительным числам.
    🔗

    Теорема 9.59 каждый положительный оператор имеет неотрицательный определитель.

    Предположим, что \(V\) — пространство со скалярным произведением, а \(T \in \Lc(V)\) — положительный оператор. Потом \(\det T \ge 0\).
    🔗
    🔗
    🔗

    Доказательство.
    По спектральной теореме ( Теорема 7.29 или Теорема 7.31) \(V\) имеет ортонормированный базис, состоящий из собственных векторов \(T{}\). Таким образом, согласно последнему пункту Примера 9.42, \(\det T\) равно произведению собственных значений \(T{}\), возможно, с повторениями. Каждое собственное значение \(T\) является неотрицательным числом (согласно теореме 7.38). Таким образом, мы приходим к выводу, что \(\det T \ge 0\).
    🔗
    🔗
    Предположим, что \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Напомним, что список неотрицательных квадратных корней из собственных значений \(T^* T\) (каждый включен столько раз, сколько его кратность) называется списком сингулярных чисел \(T\) (см. Раздел 7.5).
    🔗

    Теорема 9.60 \(\lvert \det T \rvert =\) произведение сингулярных чисел оператора \(T\).

    Предположим, что \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Тогда
    \begin{equation*} \lvert \det T \rvert = \sqrt{\det( T^*T )} = \text{ произведение сингулярных чисел } T{}. \end{equation*}
    🔗
    🔗

    Доказательство.
    У нас есть
    \begin{equation*} \lvert \det T \rvert ^2 = \overline{(\det T)} (\det T) = ( \det ( T^* ) )(\det T) = \det( T^* T ), \end{equation*}
    где среднее равенство получено из Теоремы 9.56(c), а последнее равенство — из Теоремы 9.49(a). Извлечение квадратных корней из обеих частей приведенного выше уравнения показывает, что \(\lvert \det T \rvert = \sqrt{\det( T^*T )}\).
    🔗
    Обозначим через \(s_1, \ldots, s_n\) список сингулярных чисел \(T{}\). Таким образом, \({s_1}^{2}{}, \ldots, {s_n}^{2}\) — это список собственных значений \(T^*T\) (с соответствующими повторениями), соответствующий ортонормированному базису \(V\), состоящему из собственных векторов \(T^*T{}\). Следовательно, из последнего пункта Примера 9.42 следует, что
    \begin{equation*} \det ( T^* T ) = {s_1}^{2} \cdots {s_n}^{2}{}. \end{equation*}
    🔗
    Таким образом, \(\lvert \det T \rvert = s_1 \cdots s_n\) по желанию.
    🔗
    🔗
    Оператор \(T\) в вещественном пространстве со скалярным произведением изменяет объем в произведение сингулярных чисел в раз (согласно теореме 7.111). Таким образом, следующий результат непосредственно следует из Теоремы 7.111 и Теоремы 9.60. Этот результат объясняет, почему абсолютное значение определителя появляется в формуле замены переменных в исчислении с несколькими переменными.
    🔗

    Теорема 9.61 \(T\) изменяет объём в \(\lvert \det T \rvert\) раз.

    Предположим \(T \in \Lc( \R{n} )\) и \(\Omega \subset \RR{n}\). Тогда
    \begin{equation*} \vol T(\Omega) = \lvert \det T \rvert (\vol \Omega). \end{equation*}
    🔗
    🔗
    Для операторов в конечномерных комплексных векторных пространствах мы теперь соединяем определитель с полиномом, который мы видели ранее.
    🔗

    Теорема 9.62 если \(\F{} = \C{}\), то характеристический многочлен оператора \(T\) равен \(\det(z I - T)\).

    Предположим \(\F{} = \C{}\) и \(T \in \Lc(V)\). Пусть \(\lambda_1, \ldots, \lambda_m\) обозначает различные собственные значения \(T\), а \(d_1, \ldots, d_m\) — их кратности. Тогда
    \begin{equation*} \det(zI - T) = (z - \lambda_1)^{d_1} \dotsm (z - \lambda_m)^{d_m}\!. \end{equation*}
    🔗
    🔗

    Доказательство.
    Существует базис \(V\), относительно которого \(T\) имеет верхнетреугольную матрицу, причем каждый \(\lambda_k\) появляется на диагонали ровно \(d_k\) раз (по теореме 8.37). По отношению к этому базису \(zI - T\) имеет верхнетреугольную матрицу, причем \(z - \lambda_k\) появляется на диагонали ровно \(d_k\) раз для каждого \(k\). Таким образом, Теорема 9.48 дает искомое уравнение.
    🔗
    🔗
    Предположим \(\F{} = \C{}\) и \(T \in \Lc(V)\). Характеристический полином \(T\) был определен в Определении 8.26 как полином в правой части уравнения в Теореме 9.62. Ранее мы не определяли характеристический полином оператора в конечномерном вещественном векторном пространстве, поскольку такие операторы могут не иметь собственных значений, что делает определение с использованием правой части уравнения в теореме 9.62 неуместным.
    🔗
    Теперь мы представляем новое определение характеристического полинома, основанное на теореме 9.62. Это новое определение справедливо как для вещественных, так и для комплексных векторных пространств. Уравнение в Теореме 9.62 показывает, что это новое определение эквивалентно нашему предыдущему определению, когда \(\F{} = \C{}\) Определение 8.26.
    🔗

    Определение 9.63 характеристический полином.

    Предположим, \(T \in \Lc(V)\). Полином, определенный формулой
    \begin{equation*} z \mapsto \det(zI - T) \end{equation*}
    называется характеристическим полиномом \(T\).
    🔗
    🔗
    🔗
    Формула в Теореме 9.46 показывает, что характеристический многочлен оператора \(T \in \Lc(V)\) является приведённым многочленом степени \(\dim V{}\). Нули в \(\F{}\) характеристического многочлена \(T\) являются в точности собственными значениями \(T\) (по Теореме 9.51).
    🔗
    Ранее мы доказали теорему Кэли–Гамильтона Теорема 8.29 в комплексном случае. Теперь мы можем распространить этот результат на операторы в вещественных векторных пространствах.
    🔗

    Теорема 9.64 Теорема Кэли–Гамильтона.

    Предположим, что \(T \in \Lc(V)\) и \(q\) — характеристический полином \(T{}\). Потом \(q(T) =0\).
    🔗
    🔗

    Доказательство.
    Если \(\F{} = \C{}\), то уравнение \(q(T) = 0\) следует из Теоремы 9.62 и Теоремы 8.29.
    🔗
    Теперь предположим, что \(\F{} = \R{}\). Зафиксируйте базис \(V{}\), и пусть \(A\) — матрица \(T\) относительно этого базиса. Пусть \(S\) — оператор на \(\C {\dim V}\) такой, что матрица \(S\) (относительно стандартного базиса \(\C {\dim V}\)) равна \(A\). Для всех \(z \in \R{}\) у нас есть
    \begin{equation*} q(z) = \det(zI - T) = \det(zI - A) = \det(zI - S). \end{equation*}
    🔗
    Таким образом, \(q\) является характеристическим полиномом \(S\). Теперь из случая \(\F{} = \C{}\) (первое предложение этого доказательства) следует, что \(0 = q(S) = q(A) = q(T)\).
    🔗
    🔗
    Из теоремы Кэли–Гамильтона Теорема 9.64 следует, что характеристический многочлен оператора \(T \in \Lc(V)\) является полиномиально кратным минимальному многочлену оператора \(T\) (по Теореме 5.29). Таким образом, если степень минимального многочлена \(T\) равна \(\dim V{}\), то характеристический многочлен \(T\) равен минимальному многочлену \(T{}\). Это происходит для очень большого процента операторов, включая более 99,999% матриц \(4\) на \(4\) с целочисленными элементами в \([-100, 100]\) (см. абзац после (5.25)).
    🔗
    Последнее предложение нашего следующего результата было ранее доказано в комплексном случае (см. Теорему 8.54). Теперь мы можем дать доказательство, которое работает как с вещественными, так и с комплексными векторными пространствами.
    🔗

    Теорема 9.65 характеристический полином, след и определитель.

    Предположим, \(T \in \Lc(V)\). Пусть \(n = \dim V{}\). Тогда характеристический полином \(T\) можно записать в виде
    \begin{equation*} z^n - (\tr T) z^{n-1} + \dots + (-1)^n (\det T). \end{equation*}
    🔗
    🔗

    Доказательство.
    Постоянный член полиномиальной функции от \(z\) — это значение полинома при \(z = 0\). Таким образом, постоянный член характеристического многочлена \(T\) равен \(\det(-T)\), что равно \((-1)^n \det T\) (согласно третьему пункту Примера 9.42).
    🔗
    Зафиксируйте базис \(V{}\), и пусть \(A\) — матрица \(T\) относительно этого базиса. Матрица \(zI - T\) относительно этого базиса есть \(zI - A\). Член, возникающий из тождественной перестановки \(\{ 1, \ldots, n \}\) в формуле Теорема 9.46 для \(\det(zI - A)\), равен
    \begin{equation*} (z - A_{1,1}) \cdots (z - A_{n,n}). \end{equation*}
    🔗
    Коэффициент при \(z^{n-1}\) в приведенном выше выражении равен \(-(A_{1,1} + \cdots + A_{n,n})\), что равно \(-\tr T\). Члены формулы для \(\det(zI - A)\), происходящие от других элементов \(\perm n\), содержат не более \(n-2\) множителей вида \(z - A_{k,k}\) и, таким образом, не дают вклада в коэффициент \(z^{n-1}\) в характеристическом многочлене \(T{}\).
    🔗
    🔗

    Теорема 9.66 Неравенство Адамара.

    Предположим, что \(A\) — матрица размера \(n\) на \(n\). Пусть \(v_1, \ldots, v_n\) обозначает столбцы \(A\). Тогда
    \begin{equation*} \lvert \det A \rvert \le \prod_{k=1}^n \lVert v_k \rVert . \end{equation*}
    🔗
    🔗

    Доказательство.
    Если \(A\) необратима, то \(\det A = 0\) и, следовательно, требуемое неравенство в этом случае выполнено.
    🔗
    Итак, предположим, что \(A\) обратимо. QR-факторизация Теорема 7.58 говорит нам, что существуют унитарная матрица \(Q\) и верхнетреугольная матрица \(R\), диагональ которой содержит только положительные числа такие, что \(A = QR\). У нас есть
    \begin{align*} \lvert \det A \rvert \amp = \lvert \det Q \rvert \lvert \det R \rvert\\ \amp = \lvert \det R \rvert\\ \amp = \prod_{k=1}^n R_{k,k}\\ \amp \le \prod_{k=1}^n \lVert R_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert QR_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert v_k \rVert \text{,} \end{align*}
    где первая строка взята из Теоремы 9.49(b), вторая строка взята из Теоремы 9.58, третья строка взята из Теоремы 9.48, а пятая строка справедлива, поскольку \(Q\) является изометрией.
    🔗
    🔗
    Чтобы дать геометрическую интерпретацию неравенству Адамара, предположим, что \(\F{} = \R{}\). Пусть \(T \in \Lc( \R n )\) — оператор такой, что \(Te_k = v_k\) для каждого \(k=1, \ldots, n\), где \(e_1, \ldots, e_n\) — стандартный базис \(\RR n\). Затем \(T\) отображает брус \(P(e_1, \ldots, e_n)\) на параллелепипед \(P(v_1, \ldots, v_n)\) [см. Определение 7.102 и Определение 7.105 для обзора этих обозначений и терминологии]. Поскольку брус \(P(e_1, \ldots, e_n)\) имеет объем \(1\), это означает (по Теореме 9.61), что параллелепипед \(P(v_1, \ldots, v_n)\) имеет объем \(\lvert \det T \rvert\), равный \(\lvert \det A \rvert\). Таким образом, приведенное выше неравенство Адамара можно интерпретировать следующим образом: среди всех параллелепипедов, ребра которых имеют длину \(\lVert v_1 \rVert , \ldots, \lVert v_n \rVert\), параллелепипеды с наибольшим объемом имеют ортогональные ребра (и, следовательно, имеют объем \(\prod_{k=1}^n \lVert v_k \rVert\)).
    🔗
    Чтобы узнать необходимое и достаточное условие равенства неравенства Адамара, см. Упражнение 9.3.2.18.

    Теорема 9.67 определитель матрицы Вандермонда.

    Предположим \(n > 1\) и \(\beta_1, \ldots, \beta_n \in \F{}{}\). Тогда
    \begin{equation*} \det \begin{pmatrix}1 \amp \beta_1 \amp {\beta_1}^{2} \amp \cdots \amp {\beta_1}^{n-1} \\ 1 \amp \beta_2 \amp {\beta_2}^{2} \amp \cdots \amp {\beta_2}^{n-1} \\ \\ \amp \amp \ddots \\ \\ 1 \amp \beta_n \amp {\beta_n}^{2} \amp \cdots \amp {\beta_n}^{n-1} \\ \end{pmatrix} = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j). \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(1, z, \ldots, z^{n-1}\) — стандартный базис \(\P{}_{n-1}(\F{})\), а \(e_1, \ldots, e_n\) — стандартный базис \(\FF n\). Определим линейное отображение \(\fun S { \P{}_{n-1}(\F{}) } { \F n }\) формулой
    \begin{equation*} Sp = ( p(\beta_1), \ldots, p(\beta_n) ). \end{equation*}
    🔗
    Обозначим через \(A\) матрицу Вандермонда, указанную в формулировке этого результата. Обратите внимание, что
    \begin{equation*} A = \M ( S, (1, z, \ldots, z^{n-1}), (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    Пусть \(\fun T {\P{}_{n-1}(\F{})} {\P{}_{n-1}(\F{})}\) — оператор на \(\P{}_{n-1}(\F{})\) такой, что \(T1 = 1\) и
    \begin{equation*} Tz^k = (z - \beta_1) (z - \beta_2) \cdots (z - \beta_k) \end{equation*}
    для \(k= 1, \ldots, n-1\). Пусть \(B = \M( T, (1, z, \ldots, z^{n-1}), (1, z, \ldots, z^{n-1}) )\). Тогда \(B\) — верхнетреугольная матрица, все диагональные элементы которой равны \(1\). Таким образом, \(\det B = 1\) (по теореме 9.48).
    🔗
    Пусть \(C = \M( ST, (1, z, \ldots, z^{n-1} ), (e_1, \ldots, e_n) )\). Таким образом, \(C = AB\) (по теореме 3.81), из которой следует, что
    \begin{equation*} \det A= (\det A)(\det B) =\det C. \end{equation*}
    🔗
    Определения \(C\), \(S\) и \(T\) показывают, что \(C\) равно {
    \begin{equation*} \begin{pmatrix}1 \amp 0 \amp 0 \amp \cdots \amp 0 \\ 1 \amp \beta_2 - \beta_1 \amp 0\amp \cdots \amp 0 \\ 1 \amp \beta_3 - \beta_1 \amp (\beta_3 - \beta_1)(\beta_3 - \beta_2) \amp \cdots \amp 0 \\ \\ \amp \amp \amp \ddots \\ \\ 1 \amp \beta_n - \beta _1 \amp (\beta_n - \beta_1)(\beta_n - \beta_2) \amp \cdots \amp (\beta_n - \beta_1) (\beta_n - \beta_2) \cdots (\beta_n- \beta_{n-1} ) \end{pmatrix} . \end{equation*}
    🔗
    Теперь \(\displaystyle \det A = \det C = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j)\), где мы использовали Теорему 9.56(a) и Теорему 9.48.

    где каждое \(A_k\) по диагонали представляет собой квадратную матрицу. Докажите, что

    \begin{equation*} \det \begin{pmatrix}v_{m_1} \amp \cdots \amp v_{m_n} \end{pmatrix} = ( \sign(m_1, \ldots, m_n) ) \det A. \end{equation*}

    17.

    найдя множество \(\Omega \subset \R{3}\), объем которого вам известен, и оператор \(T\) на \(\R{3}\) такой, что \(T(\Omega)\) равен эллипсоиду, указанному выше.

    20.

    Предположим, что \(A\) — матрица размера \(n\) на \(n\), и предположим, что \(c\) такова, что \(\lvert A_{j,k} \rvert \le c\) для всех \(j, k \in \{ 1, \ldots, n \}\). Докажите, что
    \begin{equation*} \lvert \det A \rvert \le c^n n^{n/2}\!. \end{equation*}
    🔗
    Примечание. Формула определителя матрицы Теорема 9.46 показывает, что \(\lvert \det A \rvert \le c^n n!\). Однако оценка, полученная в результате этого упражнения, намного лучше. Например, если \(c = 1\) и \(n = 100\), то \(c^n n! \approx 10^{158}\!\), но оценкой, полученной в этом упражнении, является гораздо меньшее число \(10^{100}\!\). Если \(n\) — целая степень \(2\), то приведенное выше неравенство является точным и не может быть улучшено.

    21.

    Предположим, что \(n\) — целое положительное число, а \(\fun \delta {\C{n,n}} {\C{}}\) — такая функция, что
    \begin{equation*} \delta(AB) = \delta(A) \cdot \delta(B) \end{equation*}
    для всех \(A, B \in \C{n,n}\) и \(\delta(A)\) равно произведению диагональных элементов \(A\) для каждой диагональной матрицы \(A \in \C{n,n}\). Докажите, что
    \begin{equation*} \delta(A) = \det A \end{equation*}
    для всех \(A \in \C{n,n}\). Примечание. Напомним, что \(\C{n,n}\) обозначает множество матриц размера \(n\) на \(n\) с элементами из  \(\C{}\). Это упражнение показывает, что определитель — это единственная функция, определенная на квадратных матрицах, которая является мультипликативной и имеет желаемое поведение на диагональных матрицах. Этот результат аналогичен упражнению 8.4.10 в разделе 8.4, которое показывает, что след однозначно определяется своими алгебраическими свойствами.
