    Раздел 9.3 Определители

    Подраздел 9.3.1 Определение определителя

    Следующее определение приведёт нас к чёткому, красивому и не зависящему от выбора базиса определению определителя оператора.
    🔗

    Определение 9.40 \(\alpha_T\).

    Пусть \(m\) — целое положительное число и \(T \in \Lc(V)\). Для каждой формы \(\alpha \in V_{\text{ alt } }^{(m)}{}\) определим форму \(\alpha_T \in V^{(m)}_{\text{ alt } }\) равенством
    \begin{equation*} \alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) \end{equation*}
    на каждом наборе векторов \(v_1, \ldots, v_m\) из \(V{}\).
    🔗
    🔗
    Пусть \(T \in \Lc(V)\). Если \(\alpha \in V^{(m)}_{\text{ alt } }\) и \(v_1, \ldots, v_m\) — такой список векторов в \(V\), что \(v_j = v_k\) при некоторых \(j \ne k\), то \(Tv_j = Tv_k\), откуда вытекает, что \(\alpha_T(v_1, \ldots, v_m) = \alpha (Tv_1, \ldots, T v_m) = 0\). Следовательно, отображение \(\alpha \mapsto \alpha_T\) является линейным отображением пространства \(V^{(m)}_{\text{ alt } }\) в себя.
    🔗
    Мы знаем, что \(\dim V^{(\dim V)}_{\text{ alt } } = 1\) (см. теорему 9.37). Всякое линейное отображение одномерного векторного пространства в себя сводится к умножению на некоторый однозначно определённый скаляр. Для линейного отображения \(\alpha \mapsto \alpha_T\) мы теперь определим \(\det T\) как этот скаляр.
    🔗

    Определение 9.41 определитель оператора, \(\det T\).

    Пусть \(T \in \Lc(V)\). Определителем оператора \(T{}\) (обозначается через \(\det T{}\)) называется единственное число из \(\F{}\), такое, что
    \begin{equation*} \alpha_T = (\det T) \alpha \end{equation*}
    для всех \(\alpha \in V_{\text{ alt } }^{(\dim V)}{}\).
    🔗
    🔗
    🔗

    Пример 9.42 определители операторов.

    Пусть \(n = \dim V{}\).
    1. Если \(I\) — тождественный оператор на \(V{}\), то \(\alpha_I = \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Следовательно, \(\det I = 1\).
      🔗
      🔗
    2. Более общо, если \(\lambda \in \F{}{}\), то \(\alpha_{\lambda I} = \lambda^n \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Следовательно, \(\det (\lambda I )= \lambda^n{}\).
      🔗
      🔗
    3. Ещё более общо, если \(T \in \Lc(V)\) и \(\lambda \in \F{}{}\), то \(\alpha_{\lambda T} = \lambda^n \alpha_T = \lambda^n (\det T) \alpha\) для всех \(\alpha \in V_{\text{ alt } }^{(n)}{}\). Следовательно, \(\det (\lambda T) = \lambda^n \det T{}\).
      🔗
      🔗
    4. Пусть \(T \in \Lc(V)\) и в пространстве \(V\) существует базис \(e_1, \ldots, e_n\), состоящий из собственных векторов оператора \(T{}\) с соответствующими собственными значениями \(\lambda_1, \ldots, \lambda_n\). Если \(\alpha \in V_{\text{ alt } }^{(n)}{}\), то
      \begin{equation*} \alpha_T(e_1, \ldots, e_n) = \alpha (\lambda_1 e_1, \ldots, \lambda_n e_n) = (\lambda_1 \cdots \lambda_n) \alpha (e_1, \ldots, e_n). \end{equation*}
      Если \(\alpha \ne 0\), то по теореме 9.39 выполняется \(\alpha (e_1, \ldots, e_n) \ne 0\). Поэтому из приведённого выше равенства следует, что
      \begin{equation*} \det T = \lambda_1 \cdots \lambda_n. \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Наша следующая задача — дать определение и вывести явную формулу для определителя квадратной матрицы. Для этого мы сопоставим каждой квадратной матрице некоторый оператор и определим определитель матрицы как определитель соответствующего оператора.
    🔗

    Определение 9.43 определитель матрицы, \(\det A\).

    Пусть \(n\) — целое положительное число и \(A\) — квадратная матрица размера \(n\) на \(n\) с элементами из \(\F{}{}\). Пусть \(T \in \Lc( \F n )\) — оператор, матрица которого в стандартном базисе пространства \(\F n\) равна \(A\). Определитель матрицы \(A\) (обозначается через \(\det A\)) определяется равенством \(\det A = \det T{}\).
    🔗
    🔗
    🔗

    Пример 9.44 определители матриц.

    1. Если \(I\) — единичная матрица размера \(n\) на \(n\), то соответствующий оператор на \(\F n\) есть тождественный оператор \(I\) на \(\FF n\). Таким образом, из первого пункта примера 9.42 вытекает, что определитель единичной матрицы равен \(1\).
      🔗
      🔗
    2. Пусть \(A\) — диагональная матрица с элементами \(\lambda_1, \ldots, \lambda_n\) на главной диагонали. Тогда для соответствующего оператора на \(\F n\) векторы стандартного базиса пространства \(\F n\) являются собственными векторами с собственными значениями \(\lambda_1, \ldots, \lambda_n\). Поэтому из последнего пункта примера 9.42 следует, что \(\det A = \lambda_1 \cdots \lambda_n\).
      🔗
      🔗
    🔗
    🔗
    В следующем результате будем рассматривать каждый набор \(v_1, \ldots, v_n\) из \(n\) векторов пространства \(\F n\) как набор векторов-столбцов размера \(n\) на \(1\). Тогда запись \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) обозначает квадратную матрицу размера \(n\) на \(n\), \(k^\nth\)-м столбцом которой является вектор \(v_k\) при каждом \(k = 1, \ldots, n\).
    🔗

    Теорема 9.45 определитель как кососимметрическая полилинейная форма.

    Пусть \(n\) — целое положительное число. Отображение, сопоставляющее набору векторов \(v_1, \ldots, v_n\) из \(\F n\) величину \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\), является кососимметрической \(n\)-линейной формой на \(\FF n\).
    🔗
    🔗

    Доказательство.
    Пусть \(e_1, \ldots, e_n\) — стандартный базис пространства \(\FF n\), а \(v_1, \ldots, v_n\) — набор векторов из \(\FF n\). Пусть \(T \in \Lc( \F n )\) — такой оператор, что \(Te_k = v_k\) при \(k = 1, \ldots, n\). Тогда \(T\) — это оператор, матрица которого в базисе \(e_1, \ldots, e_n\) имеет вид \(\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\). Следовательно, по определению определителя матрицы выполняется равенство \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} = \det T{}\).
    🔗
    Пусть \(\alpha\) — такая кососимметрическая \(n\)-линейная форма на \(\F n\), что \(\alpha (e_1, \ldots, e_n) = 1\). Тогда
    \begin{align*} \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} \amp = \det T\\ \amp = (\det T) \alpha (e_1, \ldots, e_n)\\ \amp =\alpha (Te_1, \ldots, Te_n)\\ \amp = \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
    где третье равенство следует из определения определителя оператора. Приведённая выше цепочка равенств показывает, что отображение, сопоставляющее набору векторов \(v_1, \ldots, v_n\) из \(\F n\) число \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\), совпадает с кососимметрической \(n\)-линейной формой \(\alpha\) на \(\FF n\).
    🔗
    🔗
    Предыдущий результат имеет несколько важных следствий. Например, из него сразу вытекает, что определитель матрицы с двумя одинаковыми столбцами равен \(0\). К другим следствиям мы вернёмся чуть позже, а сейчас выведем явную формулу для определителя квадратной матрицы. Напомним, что если \(A\) — матрица, то через \(A_{j,k}\) обозначается её элемент, стоящий в \(j\)-й строке и \(k\)-м столбце матрицы \(A\).
    🔗

    Теорема 9.46 формула для определителя матрицы.

    Пусть \(n\) — целое положительное число и \(A\) — квадратная матрица размера \(n\) на \(n\). Тогда
    \begin{equation*} \det A = \sum_{(j_1, \ldots, j_n) \in \perm n} ( \sign(j_1, \ldots, j_n) ) A_{j_1,1} \cdots A_{j_n,n}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Применим теорему 9.36, взяв \(V = \F n\), стандартный базис \(e_1, \ldots, e_n\) пространства \(\F n\) и кососимметрическую \(n\)-линейную форму \(\alpha\) на \(\F n\), которая переводит набор \(v_1, \ldots, v_n\) в \(\det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) [см. теорему 9.45]. Если каждый вектор \(v_k\) является \(k^\nth\)-м столбцом матрицы \(A\), то каждый коэффициент \(b_{j,k}\) в теореме 9.36 равен \(A_{j,k}\). Наконец,
    \begin{equation*} \alpha (e_1, \ldots, e_n) = \det \begin{pmatrix}e_1 \amp \cdots \amp e_n \end{pmatrix} = \det I = 1. \end{equation*}
    🔗
    Тем самым формула из теоремы 9.36 переходит в доказываемую формулу.
    🔗
    🔗

    Пример 9.47 явная формула для определителя.

    1. Если \(A\) — матрица размера \(2\) на \(2\), то формула из теоремы 9.46 принимает вид
      \begin{equation*} \det A = A_{1,1} A_{2,2} - A_{2,1} A_{1,2}. \end{equation*}
      🔗
      🔗
    2. Если \(A\) — матрица размера \(3\) на \(3\), то формула из теоремы 9.46 принимает вид
      \begin{align*} \det A = \amp A_{1,1} A_{2,2} A_{3,3} - A_{2,1} A_{1,2} A_{3,3} - A_{3,1} A_{2,2} A_{1,3}\\ \amp {}- A_{1,1} A_{3,2} A_{2,3} + A_{3,1} A_{1,2} A_{2,3} + A_{2,1} A_{3,2} A_{1,3}\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    Сумма в формуле из теоремы 9.46 содержит \(n!\) слагаемых. Поскольку факториал \(n!\) быстро растёт с увеличением \(n\), формула из теоремы 9.46 непригодна для практического вычисления определителей даже при умеренных значениях \(n\). Например, число \(10!\) превышает три миллиона, а \(100!\) приближённо равно \(10^{158}\), что приводит к сумме, которую не способен вычислить даже самый быстрый компьютер. Вскоре мы познакомимся с результатами, позволяющими вычислять определители гораздо быстрее, чем при непосредственном суммировании по формуле из теоремы 9.46.
    🔗

    Теорема 9.48 определитель верхнетреугольной матрицы.

    Пусть \(A\) — верхнетреугольная матрица с элементами \(\lambda_1, \ldots, \lambda_n\) на главной диагонали. Тогда \(\det A = \lambda_1 \cdots \lambda_n\).
    🔗
    🔗

    Доказательство.
    Если перестановка \((j_1, \ldots, j_n) \in \perm n\) удовлетворяет условию \((j_1, \ldots, j_n) \ne (1, \ldots, n)\), то \(j_k > k\) при некотором \(k \in \{ 1, \ldots, n \}\), откуда следует, что \(A_{j_k, k} = 0\). Таким образом, единственная перестановка, которая может дать ненулевой вклад в сумму из теоремы 9.46, — это тождественная перестановка \((1, \ldots, n)\). Так как \(A_{k, k} = \lambda_k\) при каждом \(k = 1, \ldots, n\), отсюда вытекает, что \(\det A = \lambda_1 \cdots \lambda_n\).
    🔗
    🔗
    🔗

    Подраздел 9.3.2 Свойства определителей

    Наше определение определителя приводит к следующему изящному доказательству мультипликативности определителя.
    🔗

    Теорема 9.49 мультипликативность определителя.

    1. Пусть \(S, T \in \Lc(V)\). Тогда \(\det (ST) = (\det S)(\det T)\).
      🔗
      🔗
    2. Пусть \(A\) и \(B\) — квадратные матрицы одного и того же размера. Тогда
      \begin{equation*} \det (AB) = (\det A)(\det B) \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    1. Пусть \(n = \dim V{}\). Возьмём произвольные \(\alpha \in V^{(n)}_{\text{ alt } }\) и \(v_1, \ldots, v_n \in V{}\). Тогда
      \begin{align*} \alpha_{ST} (v_1, \ldots, v_n) \amp = \alpha ( STv_1, \ldots, STv_n)\\ \amp = (\det S) \alpha (Tv_1, \ldots, Tv_n)\\ \amp = (\det S)(\det T) \alpha (v_1, \ldots, v_n)\text{,} \end{align*}
      где первое равенство следует из определения формы \(\alpha_{ST}\), второе — из определения \(\det S\), а третье — из определения \(\det T{}\). Из приведённой цепочки равенств вытекает, что \(\det (ST) = (\det S)(\det T)\).
      🔗
      🔗
    2. Пусть \(S, T \in \Lc( \F n )\) — такие операторы, что \(\M(S) = A\) и \(\M(T) = B\), где все матрицы операторов в этом доказательстве берутся относительно стандартного базиса пространства \(\FF n\). Тогда \(\M(ST) = \M(S) \M(T) = AB\) (см. теорему 3.43). Следовательно,
      \begin{equation*} \det(AB) = \det(ST) = (\det S)(\det T) = (\det A)(\det B), \end{equation*}
      где второе равенство следует из пункта (a).
      🔗
      🔗
    🔗
    🔗
    По определителю оператора можно судить о том, обратим ли этот оператор.
    🔗

    Теорема 9.50 обратимость \(\iff\) ненулевой определитель.

    Оператор \(T \in \Lc(V)\) обратим в том и только том случае, когда \(\det T \ne 0\). Более того, если оператор \(T\) обратим, то \(\det ( T^{-1} ) = \frac{1}{\det T}\).
    🔗
    🔗

    Доказательство.
    Пусть сначала оператор \(T\) обратим. Тогда \(T T^{-1} = I\). Из теоремы 9.49 следует, что
    \begin{equation*} 1 = \det I = \det ( TT^{-1} ) = (\det T) ( \det ( T^{-1} ) ). \end{equation*}
    🔗
    Следовательно, \(\det T \ne 0\), а число \(\det ( T^{-1} )\) обратно к \(\det T{}\).
    🔗
    Для доказательства обратного утверждения предположим, что \(\det T \ne 0\). Пусть \(v \in V\) и \(v \ne 0\). Дополним этот вектор до базиса \(v, e_2, \ldots, e_n\) пространства \(V\) и выберем форму \(\alpha \in V^{(n)}_{\text{ alt } }\) так, чтобы \(\alpha \ne 0\). Тогда \(\alpha (v, e_2, \ldots, e_n) \ne 0\) (по теореме 9.39). Имеем
    \begin{equation*} \alpha (Tv, Te_2, \ldots, Te_n) = (\det T) \alpha (v, e_2, \ldots, e_n) \ne 0. \end{equation*}
    🔗
    Значит, \(Tv \ne 0\). Следовательно, оператор \(T\) обратим.
    🔗
    🔗
    Матрица \(A\) размера \(n\) на \(n\) обратима (определение обратимой матрицы см. в определении 3.80) тогда и только тогда, когда обратим оператор на \(\F n\), сопоставленный матрице \(A\) (относительно стандартного базиса пространства \(\F n\)). Таким образом, предыдущий результат показывает, что квадратная матрица \(A\) обратима в том и только том случае, когда \(\det A \ne 0\).
    🔗

    Теорема 9.51 собственные значения и определители.

    Пусть \(T \in \Lc(V)\) и \(\lambda \in \F{}{}\). Тогда \(\lambda\) является собственным значением оператора \(T\) в том и только том случае, когда \(\det(\lambda I - T) = 0\).
    🔗
    🔗

    Доказательство.
    Число \(\lambda\) является собственным значением оператора \(T\) тогда и только тогда, когда оператор \(T - \lambda I\) необратим (см. теорему 5.7), что равносильно необратимости оператора \(\lambda I - T\), а это, в свою очередь, по теореме 9.50 равносильно равенству \(\det(\lambda I - T) = 0\).
    🔗
    🔗
    Пусть \(T \in \Lc(V)\) и \(\fun S W V\) — обратимое линейное отображение. Чтобы доказать равенство \(\det( S^{-1} T S ) = \det T\), можно было бы попытаться воспользоваться теоремой 9.49 и теоремой 9.50, записав
    \begin{align*} \det( S^{-1} T S )\amp = ( \det S^{-1} ) (\det T) (\det S)\\ \amp = \det T{}\text{.} \end{align*}
    🔗
    Такое рассуждение проходит при \(W = V{}\), но при \(W \ne V\) оно теряет смысл, поскольку определитель определён только для линейных отображений векторного пространства в себя, тогда как \(S\) отображает \(W\) в \(V{}\), ввиду чего выражение \(\det S\) не определено. Приведённое ниже доказательство обходит эту трудность и остаётся справедливым при \(W \ne V{}\).
    🔗

    Теорема 9.52 инвариантность определителя относительно подобия.

    Пусть \(T \in \Lc(V)\) и \(\fun S W V\) — обратимое линейное отображение. Тогда
    \begin{equation*} \det( S^{-1} T S ) = \det T{}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(n = \dim W = \dim V{}\). Возьмём произвольную форму \(\tau \in W_{\text{ alt } }^{(n)}{}\) и определим форму \(\alpha \in V^{(n)}_{\text{ alt } }\) равенством
    \begin{equation*} \alpha (v_1, \ldots, v_n) = \tau( S^{-1}v_1, \ldots, S^{-1}v_n ) \end{equation*}
    для \(v_1, \ldots, v_n \in V{}\). Пусть \(w_1, \ldots, w_n \in W{}\). Тогда
    \begin{align*} \tau_{S^{-1} T S}( w_1, \ldots, w_n) \amp = \tau( S^{-1}TS w_1, \ldots, S^{-1} T S w_n )\\ \amp = \alpha ( TSw_1, \ldots, TSw_n)\\ \amp = \alpha_T( Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \alpha (Sw_1, \ldots, Sw_n)\\ \amp = (\det T) \tau(w_1, \ldots, w_n)\text{.} \end{align*}
    🔗
    Из полученного соотношения и определения определителя оператора \(S^{-1} T S\) вытекает, что \(\det( S^{-1} T S ) = \det T{}\).
    🔗
    🔗
    В частном случае, когда \(V = \F n\) и \(e_1, \ldots, e_n\) — стандартный базис пространства \(\FF n\), следующий результат справедлив по самому определению определителя матрицы. Левая часть равенства в следующей теореме не зависит от выбора базиса, а значит, и правая часть не зависит от выбора базиса.
    🔗

    Теорема 9.53 совпадение определителя оператора с определителем его матрицы.

    Пусть \(T \in \Lc(V)\) и \(e_1, \ldots, e_n\) — базис пространства \(V{}\). Тогда
    \begin{equation*} \det T = \det \M( T, (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(f_1, \ldots, f_n\) — стандартный базис пространства \(\FF{n}\). Пусть \(\fun S {\F n} V\) — такое линейное отображение, что \(Sf_k = e_k\) при каждом \(k = 1, \ldots, n\). Тогда обе матрицы \(\M( S, (f_1, \ldots, f_n), (e_1, \ldots, e_n) )\) и \(\M( S^{-1} , (e_1, \ldots, e_n), (f_1, \ldots, f_n) )\) равны единичной матрице размера \(n\) на \(n\). Следовательно,
    \begin{equation} \M( S^{-1} T S, (f_1, \ldots, f_n) ) = \M( T, (e_1, \ldots, e_n) ),\tag{9.54} \end{equation}
    что вытекает из двукратного применения теоремы 3.43. Таким образом,
    \begin{align*} \det T \amp = \det( S^{-1} T S )\\ \amp = \det \M( S^{-1} T S, (f_1, \ldots, f_n) )\\ \amp = \det \M( T, (e_1, \ldots, e_n) )\text{,} \end{align*}
    где первое равенство следует из теоремы 9.52, второе — из определения определителя матрицы, а третье — из (9.54).
    🔗
    🔗
    Следующий результат даёт более наглядное представление об определителе, чем исходное определение или формула из теоремы 9.46. Свойство, установленное в приведённой ниже теореме, можно было бы принять за определение определителя оператора на конечномерном комплексном векторном пространстве, и тогда наше нынешнее определение стало бы его следствием.
    🔗

    Теорема 9.55 если \(\F{} = \C{}\), то определитель равен произведению собственных значений.

    Пусть \(\F{} = \C{}\) и \(T \in \Lc(V)\). Тогда определитель \(\det T\) равен произведению собственных значений оператора \(T{}\), причём каждое собственное значение входит в произведение столько раз, какова его кратность.
    🔗
    🔗

    Доказательство.
    В пространстве \(V\) существует базис, в котором матрица оператора \(T\) является верхнетреугольной, а на её главной диагонали стоят собственные значения оператора \(T{}\), причём каждое собственное значение встречается столько раз, какова его кратность (см. теорему 8.37). Поэтому из теоремы 9.53 и теоремы 9.48 следует, что определитель \(\det T\) равен произведению собственных значений оператора \(T{}\) с учётом их кратностей.
    🔗
    🔗
    Как показывает следующий результат, определитель хорошо согласуется с транспонированием квадратной матрицы, с переходом к двойственному оператору и с переходом к сопряжённому оператору на пространстве со скалярным произведением.
    🔗

    Теорема 9.56 определитель транспонированной матрицы, двойственного и сопряжённого операторов.

    1. Пусть \(A\) — квадратная матрица. Тогда \(\det \tran{A} = \det A\).
      🔗
      🔗
    2. Пусть \(T \in \Lc(V)\). Тогда \(\det T' = \det T{}\).
      🔗
      🔗
    3. Пусть \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Тогда
      \begin{equation*} \det ( T^* ) = \overline{\det T}{}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    1. Пусть \(n\) — целое положительное число. Зададим функцию \(\fun \alpha { ( \F n )^n} {\F{}}\) равенством
      \begin{equation*} \alpha ( v_1, \ldots, v_n ) = \det ( \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } ) \end{equation*}
      для всех \(v_1, \ldots, v_n \in \FF n\). Формула из теоремы 9.46 для определителя матрицы показывает, что \(\alpha\) является \(n\)-линейной формой на \(\FF n\). Пусть \(v_1, \ldots, v_n \in \F n\) и \(v_j = v_k\) при некоторых \(j \ne k\). Если \(B\) — произвольная матрица размера \(n\) на \(n\), то произведение \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }B\) не может равняться единичной матрице, поскольку \(j\)-я и \(k\)-я строки матрицы \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} } B\) совпадают. Следовательно, матрица \(\tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }\) необратима, откуда \(\alpha ( v_1, \ldots, v_n ) = 0\). Таким образом, \(\alpha\) — кососимметрическая \(n\)-линейная форма на \(\FF n\). Заметим, что значение формы \(\alpha\) на стандартном базисе пространства \(\F n\) равно \(1\). Поскольку векторное пространство кососимметрических \(n\)-линейных форм на \(\F n\) одномерно (по теореме 9.37), отсюда вытекает, что \(\alpha\) совпадает с определителем матрицы со столбцами из данных векторов. Тем самым пункт (a) доказан.
      🔗
      🔗
    2. Равенство \(\det T' = \det T{}\) вытекает из пункта (a), теоремы 9.53 и теоремы 3.132.
      🔗
      🔗
    3. Выберем в \(V{}\) ортонормированный базис. Матрица оператора \(T^*\) в этом базисе является эрмитово сопряжённой (комплексно сопряжённой и транспонированной) к матрице оператора \(T\) в том же базисе (по теореме 7.9). Поэтому из теоремы 9.53, теоремы 9.46 и пункта (a) следует, что \(\det ( T^* ) = \overline{\det T}{}\).
      🔗
      🔗
    🔗
    🔗

    Теорема 9.57 полезные свойства для вычисления определителей.

    1. Если в квадратной матрице совпадают два столбца или две строки, то определитель этой матрицы равен \(0\).
      🔗
      🔗
    2. Пусть \(A\) — квадратная матрица, а матрица \(B\) получена из \(A\) перестановкой местами двух столбцов или двух строк. Тогда \(\det A = - \det B\).
      🔗
      🔗
    3. При умножении некоторого столбца или некоторой строки квадратной матрицы на скаляр определитель матрицы умножается на тот же скаляр.
      🔗
      🔗
    4. Если к одному столбцу квадратной матрицы прибавить другой столбец, умноженный на скаляр, то определитель матрицы не изменится.
      🔗
      🔗
    5. Если к одной строке квадратной матрицы прибавить другую строку, умноженную на скаляр, то определитель матрицы не изменится.
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    Все утверждения этой теоремы вытекают из того, что отображения \(v_1, \ldots, v_n \mapsto \det \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) и \(v_1, \ldots, v_n \mapsto \det \tran{\begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix} }\) являются кососимметрическими \(n\)-линейными формами на \(\FF n\) [см. теорему 9.45 и теорему 9.56(a)].
    🔗
    Например, для доказательства пункта (d) предположим, что \(v_1, \ldots, v_n \in \F n\) и \(c \in \F{}{}\). Тогда
    \begin{align*} \det \amp \begin{pmatrix}v_1 + cv_2 \amp v_2 \amp \cdots \amp v_n \end{pmatrix}\\ \amp =\det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} + c\det \begin{pmatrix}v_2 \amp v_2 \amp v_3 \amp \cdots \amp v_n \end{pmatrix}\\ \amp = \det \begin{pmatrix}v_1 \amp v_2 \amp \cdots \amp v_n \end{pmatrix} \text{,} \end{align*}
    где первое равенство следует из полилинейности, а второе — из кососимметричности. Приведённое выше равенство показывает, что прибавление к первому столбцу второго столбца, умноженного на скаляр, не меняет определителя. То же самое рассуждение применимо к любым двум столбцам. Тем самым пункт (d) доказан.
    🔗
    Утверждение (e) вытекает из (d) и теоремы 9.56(a). Доказательства пунктов (a), (b) и (c) опираются на аналогичные соображения и предоставляются читателю.
    🔗
    🔗
    Для матриц с конкретными числовыми элементами доказанная теорема даёт гораздо более быстрый способ вычисления определителя, чем непосредственное применение формулы из теоремы 9.46. А именно, с помощью метода Гаусса — переставляя строки [по теореме 9.57(b) при этом определитель умножается на \(-1\)], умножая строку на ненулевую константу [по теореме 9.57(c) определитель умножается на ту же константу] и прибавляя к одной строке другую, умноженную на скаляр [по теореме 9.57(e) это не меняет определителя], — приведём матрицу к верхнетреугольному виду; определитель полученной верхнетреугольной матрицы равен произведению её диагональных элементов (по теореме 9.48). Отслеживая число перестановок строк и множители, на которые умножались строки, можно легко найти определитель исходной матрицы.
    🔗
    Поскольку число \(\lambda \in \F{}\) является собственным значением оператора \(T \in \Lc(V)\) тогда и только тогда, когда \(\det(\lambda I - T) = 0\) (по теореме 9.51), может возникнуть соблазн искать собственные значения следующим образом: выбрать базис пространства \(V{}\), положить \(A = \M(T)\), вычислить \(\det(\lambda I - A)\) и затем решить уравнение \(\det(\lambda I - A) = 0\) относительно \(\lambda\). Однако такой подход редко бывает эффективным, за исключением случая \(\dim V = 2\) (или случаев, когда размерность \(\dim V\) равна \(3\) или \(4\), если вы готовы пользоваться формулами Кардано и Феррари для уравнений третьей и четвёртой степени). Одна из трудностей состоит в том, что описанный в предыдущем абзаце алгоритм вычисления определителя не работает, когда матрица содержит символьную переменную (такую как \(\lambda\) в \(\lambda I - A\)). Дело в том, что в процессе исключения по методу Гаусса необходимо проверять, равны ли те или иные выражения нулю (\(0\)), а для выражений, зависящих от символьного параметра \(\lambda\), это становится весьма непростой задачей.
    🔗
    Напомним, что оператор на конечномерном пространстве со скалярным произведением называется унитарным, если он сохраняет норму (см. определение 7.51 и следующий за ним абзац). Модуль каждого собственного значения унитарного оператора равен \(1\) (по теореме 7.54). Поэтому модуль произведения собственных значений унитарного оператора равен \(1\). Следовательно (по крайней мере в случае \(\F{} = \C{}\)), модуль определителя унитарного оператора равен \(1\) (по теореме 9.55). В следующей теореме приводится доказательство этого факта, не использующее предположения \(\F{} = \C{}\).
    🔗

    Теорема 9.58 определитель любого унитарного оператора по модулю равен \(1\).

    Пусть \(V\) — пространство со скалярным произведением и \(S \in \Lc(V)\) — унитарный оператор. Тогда \(\lvert \det S \rvert = 1\).
    🔗
    🔗
    🔗

    Доказательство.
    Поскольку оператор \(S\) унитарен, имеем \(I = S^* S\) (см. теорему 7.53). Следовательно,
    \begin{equation*} 1 = \det(S^* S) = (\det S^*) (\det S) = \overline{( \det S)} (\det S) = \lvert \det S \rvert ^2{}, \end{equation*}
    где второе равенство вытекает из теоремы 9.49(a), а третье — из теоремы 9.56(c). Из полученного соотношения следует, что \(\lvert \det S \rvert = 1\).
    🔗
    🔗
    Свойства определителя положительного оператора на пространстве со скалярным произведением прекрасно согласуются с аналогией между положительными операторами и неотрицательными вещественными числами.

    Теорема 9.59 неотрицательность определителя положительного оператора.

    Пусть \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\) — положительный оператор. Тогда \(\det T \ge 0\).
    🔗
    🔗
    🔗

    Доказательство.
    По спектральной теореме (теорема 7.29 или теорема 7.31) в пространстве \(V\) существует ортонормированный базис, состоящий из собственных векторов оператора \(T{}\). Следовательно, согласно последнему пункту примера 9.42, определитель \(\det T\) равен произведению собственных значений оператора \(T{}\) (возможно, с повторениями). Каждое собственное значение оператора \(T\) является неотрицательным числом (по теореме 7.38). Отсюда заключаем, что \(\det T \ge 0\).
    🔗
    🔗
    Пусть \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Напомним, что список неотрицательных квадратных корней из собственных значений оператора \(T^* T\) (каждое из которых берётся столько раз, какова его кратность) называется списком сингулярных чисел оператора \(T\) (см. раздел 7.5).
    🔗

    Теорема 9.60 \(\lvert \det T \rvert =\) произведение сингулярных чисел оператора \(T\).

    Пусть \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Тогда
    \begin{equation*} \lvert \det T \rvert = \sqrt{\det( T^*T )} = \text{ произведение сингулярных чисел } T{}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Имеем
    \begin{equation*} \lvert \det T \rvert ^2 = \overline{(\det T)} (\det T) = ( \det ( T^* ) )(\det T) = \det( T^* T ), \end{equation*}
    где среднее равенство следует из теоремы 9.56(c), а последнее — из теоремы 9.49(a). Извлекая квадратный корень из обеих частей этого равенства, получаем \(\lvert \det T \rvert = \sqrt{\det( T^*T )}\).
    🔗
    Пусть \(s_1, \ldots, s_n\) — список сингулярных чисел оператора \(T{}\). Тогда \({s_1}^{2}{}, \ldots, {s_n}^{2}\) — список собственных значений оператора \(T^*T\) (с соответствующими повторениями), отвечающих ортонормированному базису пространства \(V\) из собственных векторов оператора \(T^*T{}\). Следовательно, согласно последнему пункту примера 9.42,
    \begin{equation*} \det ( T^* T ) = {s_1}^{2} \cdots {s_n}^{2}{}. \end{equation*}
    🔗
    Следовательно, \(\lvert \det T \rvert = s_1 \cdots s_n\), что и требовалось доказать.
    🔗
    🔗
    Оператор \(T\) на вещественном пространстве со скалярным произведением изменяет объём в число раз, равное произведению его сингулярных чисел (по теореме 7.111). Поэтому следующий результат непосредственно вытекает из теоремы 7.111 и теоремы 9.60. Он объясняет, почему в формуле замены переменных в кратном интеграле появляется модуль определителя (якобиана).

    Теорема 9.61 \(T\) изменяет объём в \(\lvert \det T \rvert\) раз.

    Пусть \(T \in \Lc( \R{n} )\) и \(\Omega \subset \RR{n}\). Тогда
    \begin{equation*} \vol T(\Omega) = \lvert \det T \rvert (\vol \Omega). \end{equation*}
    🔗
    🔗
    Для операторов на конечномерных комплексных векторных пространствах мы теперь свяжем определитель с уже знакомым нам многочленом.
    🔗

    Теорема 9.62 если \(\F{} = \C{}\), то характеристический многочлен оператора \(T\) равен \(\det(z I - T)\).

    Пусть \(\F{} = \C{}\) и \(T \in \Lc(V)\). Обозначим через \(\lambda_1, \ldots, \lambda_m\) попарно различные собственные значения оператора \(T\), а через \(d_1, \ldots, d_m\) — их кратности. Тогда
    \begin{equation*} \det(zI - T) = (z - \lambda_1)^{d_1} \dotsm (z - \lambda_m)^{d_m}\!. \end{equation*}
    🔗
    🔗

    Доказательство.
    В пространстве \(V\) существует базис, в котором матрица оператора \(T\) верхнетреугольна, причём каждое собственное значение \(\lambda_k\) встречается на главной диагонали ровно \(d_k\) раз (по теореме 8.37). В этом базисе оператор \(zI - T\) также имеет верхнетреугольную матрицу, на диагонали которой при каждом \(k\) элемент \(z - \lambda_k\) встречается ровно \(d_k\) раз. Применяя теорему 9.48, получаем требуемое равенство.
    🔗
    🔗
    Пусть \(\F{} = \C{}\) и \(T \in \Lc(V)\). Характеристический многочлен оператора \(T\) был определён в определении 8.26 как многочлен, стоящий в правой части равенства из теоремы 9.62. Ранее мы не определяли характеристический многочлен оператора на конечномерном вещественном векторном пространстве, поскольку такой оператор может вовсе не иметь собственных значений, что делает определение через правую часть формулы из теоремы 9.62 неприменимым.
    🔗
    Теперь, опираясь на теорему 9.62, мы дадим новое определение характеристического многочлена, пригодное как для вещественных, так и для комплексных векторных пространств. Равенство в теореме 9.62 показывает, что при \(\F{} = \C{}\) это новое определение равносильно прежнему определению 8.26.
    🔗

    Определение 9.63 характеристический многочлен.

    Пусть \(T \in \Lc(V)\). Многочлен, заданный формулой
    \begin{equation*} z \mapsto \det(zI - T) \end{equation*}
    называется характеристическим многочленом оператора \(T\).
    🔗
    🔗
    🔗
    Формула из теоремы 9.46 показывает, что характеристический многочлен оператора \(T \in \Lc(V)\) является приведённым многочленом степени \(\dim V{}\). Корни характеристического многочлена оператора \(T\) в поле \(\F{}\) — это в точности собственные значения оператора \(T\) (по теореме 9.51).
    🔗
    Ранее мы доказали теорему Гамильтона — Кэли (теорема 8.29) в комплексном случае. Теперь мы можем распространить этот результат на операторы в вещественных векторных пространствах.
    🔗

    Теорема 9.64 теорема Кэли — Гамильтона.

    Пусть \(T \in \Lc(V)\) и \(q\) — характеристический многочлен оператора \(T{}\). Тогда \(q(T) =0\).
    🔗
    🔗

    Доказательство.
    Если \(\F{} = \C{}\), то равенство \(q(T) = 0\) вытекает из теоремы 9.62 и теоремы 8.29.
    🔗
    Пусть теперь \(\F{} = \R{}\). Зафиксируем базис пространства \(V{}\) и обозначим через \(A\) матрицу оператора \(T\) в этом базисе. Пусть \(S\) — такой оператор на \(\C {\dim V}\), что матрица оператора \(S\) (в стандартном базисе пространства \(\C {\dim V}\)) равна \(A\). Для всех \(z \in \R{}\) имеем
    \begin{equation*} q(z) = \det(zI - T) = \det(zI - A) = \det(zI - S). \end{equation*}
    🔗
    Следовательно, \(q\) является характеристическим многочленом оператора \(S\). Из уже рассмотренного случая \(\F{} = \C{}\) (см. первое предложение доказательства) теперь вытекает, что \(0 = q(S) = q(A) = q(T)\).
    🔗
    🔗
    Из теоремы Гамильтона — Кэли (теорема 9.64) следует, что характеристический многочлен оператора \(T \in \Lc(V)\) делится на минимальный многочлен оператора \(T\) (по теореме 5.29). Поэтому если степень минимального многочлена оператора \(T\) равна \(\dim V{}\), то характеристический многочлен оператора \(T\) совпадает с минимальным многочленом оператора \(T{}\). Так обстоит дело для подавляющего большинства операторов, включая более 99,999% матриц размера \(4\) на \(4\) с целыми элементами из отрезка \([-100, 100]\) (см. абзац после (5.25)).
    🔗
    Последнее утверждение следующей теоремы ранее было доказано в комплексном случае (см. теорему 8.54). Теперь мы можем дать доказательство, справедливое как для вещественных, так и для комплексных векторных пространств.
    🔗

    Теорема 9.65 характеристический многочлен, след и определитель.

    Пусть \(T \in \Lc(V)\) и \(n = \dim V{}\). Тогда характеристический многочлен оператора \(T\) можно записать в виде
    \begin{equation*} z^n - (\tr T) z^{n-1} + \dots + (-1)^n (\det T). \end{equation*}
    🔗
    🔗

    Доказательство.
    Свободный член многочлена от переменной \(z\) равен его значению при \(z = 0\). Следовательно, свободный член характеристического многочлена оператора \(T\) равен \(\det(-T)\), что совпадает с \((-1)^n \det T\) (согласно третьему пункту примера 9.42).
    🔗
    Зафиксируем базис пространства \(V{}\) и обозначим через \(A\) матрицу оператора \(T\) в этом базисе. Матрица оператора \(zI - T\) в этом базисе имеет вид \(zI - A\). Слагаемое в формуле из теоремы 9.46 для \(\det(zI - A)\), отвечающее тождественной перестановке \(\{ 1, \ldots, n \}\), равно
    \begin{equation*} (z - A_{1,1}) \cdots (z - A_{n,n}). \end{equation*}
    🔗
    Коэффициент при \(z^{n-1}\) в этом выражении равен \(-(A_{1,1} + \cdots + A_{n,n})\), то есть равен \(-\tr T\). Слагаемые в формуле для \(\det(zI - A)\), отвечающие остальным перестановкам из \(\perm n\), содержат не более \(n-2\) сомножителей вида \(z - A_{k,k}\) и потому не дают вклада в коэффициент при \(z^{n-1}\) в характеристическом многочлене оператора \(T{}\).
    🔗
    🔗

    Теорема 9.66 неравенство Адамара.

    Пусть \(A\) — матрица размера \(n\) на \(n\), и пусть \(v_1, \ldots, v_n\) — столбцы матрицы \(A\). Тогда
    \begin{equation*} \lvert \det A \rvert \le \prod_{k=1}^n \lVert v_k \rVert . \end{equation*}
    🔗
    🔗

    Доказательство.
    Если матрица \(A\) необратима, то \(\det A = 0\), и в этом случае требуемое неравенство очевидно выполняется.
    🔗
    Поэтому будем считать, что матрица \(A\) обратима. Согласно теореме о QR-разложении (теорема 7.58) существуют такие унитарная матрица \(Q\) и верхнетреугольная матрица \(R\) с положительными элементами на главной диагонали, что \(A = QR\). Имеем
    \begin{align*} \lvert \det A \rvert \amp = \lvert \det Q \rvert \lvert \det R \rvert\\ \amp = \lvert \det R \rvert\\ \amp = \prod_{k=1}^n R_{k,k}\\ \amp \le \prod_{k=1}^n \lVert R_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert QR_{\cdot, k} \rVert\\ \amp = \prod_{k=1}^n \lVert v_k \rVert \text{,} \end{align*}
    где первая строка следует из теоремы 9.49(b), вторая — из теоремы 9.58, третья — из теоремы 9.48, а пятая справедлива в силу того, что \(Q\) — изометрия.
    🔗
    🔗
    Чтобы дать геометрическую интерпретацию неравенства Адамара, положим \(\F{} = \R{}\). Пусть \(T \in \Lc( \R n )\) — такой оператор, что \(Te_k = v_k\) при каждом \(k=1, \ldots, n\), где \(e_1, \ldots, e_n\) — стандартный базис пространства \(\RR n\). Тогда оператор \(T\) переводит единичный куб \(P(e_1, \ldots, e_n)\) в параллелепипед \(P(v_1, \ldots, v_n)\) [соответствующие обозначения и терминологию см. в определении 7.102 и определении 7.105]. Поскольку объём куба \(P(e_1, \ldots, e_n)\) равен \(1\), по теореме 9.61 отсюда следует, что объём параллелепипеда \(P(v_1, \ldots, v_n)\) равен \(\lvert \det T \rvert\), то есть равен \(\lvert \det A \rvert\). Таким образом, неравенство Адамара означает, что среди всех параллелепипедов с заданными длинами рёбер \(\lVert v_1 \rVert , \ldots, \lVert v_n \rVert\) наибольший объём имеют прямоугольные параллелепипеды, т. е. параллелепипеды с попарно ортогональными рёбрами (и их объём равен \(\prod_{k=1}^n \lVert v_k \rVert\)).
    🔗
    Необходимое и достаточное условие обращения неравенства Адамара в равенство приведено в упражнении 9.3.2.18.

    Теорема 9.67 определитель матрицы Вандермонда.

    Пусть \(n > 1\) и \(\beta_1, \ldots, \beta_n \in \F{}{}\). Тогда
    \begin{equation*} \det \begin{pmatrix}1 \amp \beta_1 \amp {\beta_1}^{2} \amp \cdots \amp {\beta_1}^{n-1} \\ 1 \amp \beta_2 \amp {\beta_2}^{2} \amp \cdots \amp {\beta_2}^{n-1} \\ \\ \amp \amp \ddots \\ \\ 1 \amp \beta_n \amp {\beta_n}^{2} \amp \cdots \amp {\beta_n}^{n-1} \\ \end{pmatrix} = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j). \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(1, z, \ldots, z^{n-1}\) — стандартный базис пространства \(\P{}_{n-1}(\F{})\), а \(e_1, \ldots, e_n\) — стандартный базис пространства \(\FF n\). Зададим линейное отображение \(\fun S { \P{}_{n-1}(\F{}) } { \F n }\) формулой
    \begin{equation*} Sp = ( p(\beta_1), \ldots, p(\beta_n) ). \end{equation*}
    🔗
    Обозначим через \(A\) матрицу Вандермонда, изображённую в формулировке теоремы. Заметим, что
    \begin{equation*} A = \M ( S, (1, z, \ldots, z^{n-1}), (e_1, \ldots, e_n) ). \end{equation*}
    🔗
    Пусть \(\fun T {\P{}_{n-1}(\F{})} {\P{}_{n-1}(\F{})}\) — такой оператор на \(\P{}_{n-1}(\F{})\), что \(T1 = 1\) и
    \begin{equation*} Tz^k = (z - \beta_1) (z - \beta_2) \cdots (z - \beta_k) \end{equation*}
    при \(k= 1, \ldots, n-1\). Положим \(B = \M( T, (1, z, \ldots, z^{n-1}), (1, z, \ldots, z^{n-1}) )\). Тогда \(B\) — верхнетреугольная матрица, все диагональные элементы которой равны \(1\). Следовательно, \(\det B = 1\) (по теореме 9.48).
    🔗
    Положим \(C = \M( ST, (1, z, \ldots, z^{n-1} ), (e_1, \ldots, e_n) )\). Тогда \(C = AB\) (по теореме 3.81), откуда вытекает, что
    \begin{equation*} \det A= (\det A)(\det B) =\det C. \end{equation*}
    🔗
    Из определений \(C\), \(S\) и \(T\) видно, что матрица \(C\) равна {
    \begin{equation*} \begin{pmatrix}1 \amp 0 \amp 0 \amp \cdots \amp 0 \\ 1 \amp \beta_2 - \beta_1 \amp 0\amp \cdots \amp 0 \\ 1 \amp \beta_3 - \beta_1 \amp (\beta_3 - \beta_1)(\beta_3 - \beta_2) \amp \cdots \amp 0 \\ \\ \amp \amp \amp \ddots \\ \\ 1 \amp \beta_n - \beta _1 \amp (\beta_n - \beta_1)(\beta_n - \beta_2) \amp \cdots \amp (\beta_n - \beta_1) (\beta_n - \beta_2) \cdots (\beta_n- \beta_{n-1} ) \end{pmatrix} . \end{equation*}
    🔗
    Теперь получаем \(\displaystyle \det A = \det C = \prod_{1 \le j \lt k \le n} (\beta_k - \beta_j)\), где мы воспользовались теоремой 9.56(a) и теоремой 9.48.
    🔗

    Упражнения Упражнения

    1.

    2.

    Пусть первый столбец квадратной матрицы \(A\) состоит из одних нулей, за возможным исключением первого элемента \(A_{1,1}\). Пусть \(B\) — матрица, полученная из \(A\) вычёркиванием первой строки и первого столбца матрицы \(A\). Покажите, что \(\det A = A_{1,1} \det B\).
    🔗
    🔗

    3.

    Пусть оператор \(T \in \Lc(V)\) нильпотентен. Докажите, что \(\det(I + T) = 1\).
    🔗
    🔗

    4.

    Пусть \(S \in \Lc(V)\). Докажите, что оператор \(S\) унитарен в том и только том случае, когда \(\lvert \det S \rvert = \lVert S \rVert = 1\).
    🔗
    🔗

    5.

    Пусть \(A\) — блочно-верхнетреугольная матрица
    \begin{equation*} A = \begin{pmatrix}A_1 \amp \amp * \\ \amp \ddots \amp \\ 0 \amp \amp A_m \end{pmatrix} , \end{equation*}
    где каждый диагональный блок \(A_k\) является квадратной матрицей. Докажите, что
    \begin{equation*} \det A = (\det A_1) \dotsm (\det A_m). \end{equation*}
    🔗
    🔗

    6.

    Пусть \(A = \begin{pmatrix}v_1 \amp \cdots \amp v_n \end{pmatrix}\) — матрица размера \(n\) на \(n\), в которой через \(v_k\) обозначен \(k^\nth\)-й столбец матрицы \(A\). Покажите, что если \((m_1, \ldots, m_n) \in \perm n\), то
    \begin{equation*} \det \begin{pmatrix}v_{m_1} \amp \cdots \amp v_{m_n} \end{pmatrix} = ( \sign(m_1, \ldots, m_n) ) \det A. \end{equation*}
    🔗
    🔗

    7.

    Пусть оператор \(T \in \Lc(V)\) обратим. Обозначим через \(p\) характеристический многочлен оператора \(T\), а через \(q\) — характеристический многочлен оператора \(T^{-1}\). Докажите, что
    \begin{equation*} q(z) = \frac{1}{p(0)} z^{\dim V} p( \frac{1}{z} ) \end{equation*}
    для всех ненулевых \(z \in \F{}{}\).
    🔗
    🔗

    8.

    Пусть \(T \in \Lc(V)\) — оператор, не имеющий собственных значений (откуда следует, что \(\F{} = \R{}\)). Докажите, что \(\det T > 0\).
    🔗
    🔗

    9.

    Пусть \(V\) — вещественное векторное пространство чётной размерности, \(T \in \Lc(V)\) и \(\det T \lt 0\). Докажите, что оператор \(T\) имеет по крайней мере два различных собственных значения.
    🔗
    🔗

    10.

    Пусть \(V\) — вещественное векторное пространство нечётной размерности и \(T \in \Lc(V)\). Не используя минимальный многочлен, докажите, что оператор \(T\) имеет собственное значение. Примечание: Ранее этот результат был доказан без использования определителей и характеристического многочлена — см. теорему 5.34.
    🔗
    🔗

    11.

    Докажите или приведите контрпример: если \(\F{} = \R{}\), \(T \in \Lc(V)\) и \(\det T > 0\), то у оператора \(T\) существует квадратный корень. Примечание: Если \(\F{} = \C{}\), \(T \in \Lc(V)\) и \(\det T \ne 0\), то у оператора \(T\) существует квадратный корень (см. теорему 8.41).
    🔗
    🔗

    12.

    Пусть \(S, T \in \Lc(V)\), причём оператор \(S\) обратим. Зададим функцию \(\fun p {\F{}} {\F{}}\) формулой
    \begin{equation*} p(z) = \det(zS - T). \end{equation*}
    🔗
    Докажите, что \(p\) — многочлен степени \(\dim V\) и что коэффициент при \(z^{\dim V}\) в этом многочлене равен \(\det S\).
    🔗
    🔗

    13.

    Пусть \(\F{} = \C{}\), \(T \in \Lc(V)\) и \(n = \dim V > 2\). Обозначим через \(\lambda_1, \ldots, \lambda_n\) собственные значения оператора \(T\), причём каждое собственное значение повторяется столько раз, какова его кратность.
    1. Выразите коэффициент при \(z^{n-2}\) в характеристическом многочлене оператора \(T\) через \(\lambda_1, \ldots, \lambda_n\).
      🔗
      🔗
    2. Выразите коэффициент при \(z\) в характеристическом многочлене оператора \(T\) через \(\lambda_1, \ldots, \lambda_n\).
      🔗

    14.

    Пусть \(V\) — пространство со скалярным произведением и \(T\) — положительный оператор на \(V{}\). Докажите, что
    \begin{equation*} \det \sqrt{T} = \sqrt{ \det T }. \end{equation*}
    🔗

    15.

    Пусть \(V\) — пространство со скалярным произведением и \(T \in \Lc(V)\). Используя полярное разложение, дайте доказательство равенства
    \begin{equation*} \lvert \det T \rvert = \sqrt{\det( T^*T )} \end{equation*}
    отличное от приведённого ранее (см. теорему 9.60).
    🔗

    16.

    Пусть \(T \in \Lc(V)\). Зададим функцию \(\fun g {\F{}} {\F{}}\) формулой \(g(x) = \det(I + xT)\). Покажите, что \(g'(0) = \tr T{}\). Примечание: Постарайтесь найти краткое и изящное решение этого упражнения, не прибегая к явной, но громоздкой формуле для определителя матрицы.
    🔗
    🔗

    17.

    Пусть \(a, b, c\) — положительные числа. Найдите объём эллипсоида
    \begin{equation*} \{ (x, y, z) \in \R{3}: \frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} \lt 1 \} \end{equation*}
    подобрав множество \(\Omega \subset \R{3}\) известного вам объёма и такой оператор \(T\) на \(\R{3}\), что образ \(T(\Omega)\) совпадает с указанным эллипсоидом.
    🔗
    🔗

    18.

    Пусть \(A\) — обратимая квадратная матрица. Докажите, что неравенство Адамара (теорема 9.66) обращается в равенство в том и только том случае, когда столбцы матрицы \(A\) попарно ортогональны.
    🔗
    🔗

    19.

    Пусть \(V\) — пространство со скалярным произведением, \(e_1, \ldots, e_n\) — ортонормированный базис пространства \(V{}\), а \(T \in \Lc(V)\) — положительный оператор.
    1. Докажите, что \(\det T \le \prod_{k=1}^n \langle Te_k, e_k \rangle\).
      🔗
      🔗
    2. Докажите, что если оператор \(T\) обратим, то неравенство в пункте (a) обращается в равенство тогда и только тогда, когда при каждом \(k = 1, \ldots, n\) вектор \(e_k\) является собственным вектором оператора \(T\).
      🔗
      🔗
    🔗
    🔗

    20.

    Пусть \(A\) — матрица размера \(n\) на \(n\) и число \(c\) таково, что \(\lvert A_{j,k} \rvert \le c\) для всех \(j, k \in \{ 1, \ldots, n \}\). Докажите, что
    \begin{equation*} \lvert \det A \rvert \le c^n n^{n/2}\!. \end{equation*}
    🔗
    Примечание: Из явной формулы для определителя матрицы (теорема 9.46) видно, что \(\lvert \det A \rvert \le c^n n!\). Однако оценка из данного упражнения гораздо точнее. Например, при \(c = 1\) и \(n = 100\) имеем \(c^n n! \approx 10^{158}\!\), тогда как оценка из этого упражнения даёт намного меньшее число \(10^{100}\!\). Если же \(n\) является целой степенью числа \(2\), то приведённое выше неравенство является точным и не может быть улучшено.
    🔗
    🔗

    21.

    Пусть \(n\) — целое положительное число и \(\fun \delta {\C{n,n}} {\C{}}\) — такая функция, что
    \begin{equation*} \delta(AB) = \delta(A) \cdot \delta(B) \end{equation*}
    для всех \(A, B \in \C{n,n}\), причём для каждой диагональной матрицы \(A \in \C{n,n}\) значение \(\delta(A)\) равно произведению диагональных элементов матрицы \(A\). Докажите, что
    \begin{equation*} \delta(A) = \det A \end{equation*}
    для всех \(A \in \C{n,n}\). Примечание: Напомним, что через \(\C{n,n}\) обозначается множество матриц размера \(n\) на \(n\) с элементами из \(\C{}\). Это упражнение показывает, что определитель — единственная функция на квадратных матрицах, которая мультипликативна и принимает предписанные значения на диагональных матрицах. Этот результат аналогичен упражнению 8.4.10 из раздела 8.4, где показано, что след однозначно определяется своими алгебраическими свойствами.
