Определение 1.20 векторное пространство.

Векторное пространство — это множество \(V\) вместе с операцией сложения на \(V\) и операцией умножения на скаляр на \(V\), для которых выполняются следующие свойства.
  1. коммутативность.
    \(u + v = v + u\) для всех \(u, v \in V{}\).
    🔗
    🔗
  2. ассоциативность.
    \((u + v) + w = u + (v + w)\) и \((ab)v = a(bv)\) для всех \(u, v, w \in V\) и для всех \(a, b \in \F{}{}\).
    🔗
    🔗
  3. нулевой элемент.
    Существует элемент \(0 \in V\) такой, что \(v + 0 = v\) для всех \(v \in V{}\).
    🔗
    🔗
  4. противоположный элемент.
    Для каждого \(v \in V{}\) существует \(w \in V\) такой, что \(v + w = 0\).
    🔗
    🔗
  5. мультипликативное тождество.
    \(1v = v\) для всех \(v \in V{}\).
    🔗
    🔗
  6. распределительные свойства.
    \(a(u + v) = au + av\) и \((a + b)v = av + bv\) для всех \(a, b \in \F{}\) и всех \(u, v \in V{}\).
    🔗
    🔗
