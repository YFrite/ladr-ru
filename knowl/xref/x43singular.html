Пример 7.67 сингулярные числа линейного отображения из \(\F4\) в \(\F3\).

Пусть отображение \(T \in \Lc( \F4, \F3 )\) имеет (относительно стандартных базисов) матрицу
\begin{equation*} \begin{pmatrix}0 \amp 0 \amp 0 \amp -5 \\ 0 \amp 0 \amp 0 \amp 0\\ 1 \amp 1 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
🔗
Нетрудно проверить, что матрица оператора \(T^* T\) имеет вид
\begin{equation*} \begin{pmatrix}1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 0\amp 0\\ 0 \amp 0 \amp 0 \amp 25 \end{pmatrix} \end{equation*}
и что собственными значениями оператора \(T^*T\) являются числа \(25\), \(2\), \(0\), причём \(\dim E( 25, T^* T ) = 1\), \(\dim E( 2, T^* T ) = 1\) и \(\dim E( 0, T^*T ) = 2\). Следовательно, сингулярными числами отображения \(T\) являются \(5, \sqrt{2}, 0, 0\).
