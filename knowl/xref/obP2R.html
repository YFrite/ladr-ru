Пример 6.34 ортонормированный базис пространства \(\P_2(\R{})\).

Превратим пространство \(\P{}_2(\R{})\) в пространство со скалярным произведением, задав скалярное произведение формулой
\begin{equation*} \langle p, q \rangle = \int_{-1}^{1} pq \end{equation*}
для всех \(p, q \in \P{}_2(\R{})\). Мы знаем, что \(1, x, x^2\) — базис пространства \(\P{}_2(\R{})\), однако он не является ортонормированным. Найдём ортонормированный базис пространства \(\P{}_2(\R{})\), применив процесс ортогонализации Грама — Шмидта к векторам \(v_1 = 1\), \(v_2 = x\) и \(v_3 = x^2{}\).
🔗
Начнём с \(f_1 = v_1 = 1\). Тогда \(\lVert f_1 \rVert ^2 = \int_{-1}^1 1 = 2\). Следовательно, по формуле из Теоремы 6.32 получаем
\begin{equation*} f_2 = v_2 - \frac{\langle v_2, f_1 \rangle }{\lVert f_1 \rVert ^2} f_1 = x - \frac{\langle x, 1 \rangle }{\lVert f_1 \rVert ^2} = x, \end{equation*}
где последнее равенство справедливо, так как \(\langle x, 1 \rangle = \int_{-1}^1 t dt = 0\).
🔗
Из полученной формулы для \(f_2\) следует, что \(\lVert f_2 \rVert ^2 = \int_{-1}^1 t^2 dt = \frac{2}{3}\). Теперь формула из Теоремы 6.32 даёт
\begin{align*} f_3 =\mathstrut\amp v_3 - \frac{\langle v_3, f_1 \rangle }{\lVert f_1 \rVert ^2} f_1 - \frac{\langle v_3, f_2 \rangle }{\lVert f_2 \rVert ^2} f_2 \\ =\mathstrut\amp x^2 - \tfrac{1}{2} \langle x^2{}, 1 \rangle - \tfrac{3}{2}\langle x^2{}, x \rangle x \\ =\mathstrut\amp x^2 - \tfrac{1}{3}\text{.} \end{align*}
🔗
Из этой формулы для \(f_3\) вытекает, что
\begin{equation*} \lVert f_3 \rVert ^2 = \int_{-1}^1 ( t^2 - \tfrac{1}{3} )^2 dt = \int_{-1}^{1} ( t^4 -\tfrac{2}{3} t^2 + \tfrac{1}{9} ) dt = \tfrac{8}{45}. \end{equation*}
🔗
Разделив теперь каждый из векторов \(f_1, f_2, f_3\) на его норму, получим ортонормированную систему
\begin{equation*} \sqrt{\tfrac{1}{2}}, \sqrt{\tfrac{3}{2}} x, \sqrt{\tfrac{45}{8}} ( x^2 - \tfrac{1}{3} ). \end{equation*}
🔗
Построенная ортонормированная система состоит из трёх векторов, что совпадает с размерностью пространства \(\P{}_2(\R{})\). Следовательно, эта система является ортонормированным базисом пространства \(\P{}_2(\R{})\) [по Теореме 6.28].
