Упражнение 10.

Докажите, что след — единственный линейный функционал \(\fun \tau {\Lc(V)} {\F{}}\), для которого
\begin{equation*} \tau(ST) = \tau(TS) \end{equation*}
для всех \(S, T \in \Lc(V)\) и \(\tau(I) = \dim V{}\).
🔗
Подсказка.
Пусть \(v_1, \ldots, v_n\) — базис пространства \(V{}\). Для \(j, k \in \{ 1, \ldots, n \}\) определим оператор \(P_{j,k} \in \Lc(V)\) формулой \(P_{j,k}(a_1 v_1 + \cdots + a_n v_n) = a_k v_j\). Докажите, что
\begin{equation*} \tau(P_{j,k}) = \begin{cases}1 \amp \text{ если } j = k, \\ 0 \amp \text{ если } j \ne k. \end{cases} \end{equation*}
🔗
Затем для произвольного оператора \(T \in \Lc(V)\) воспользуйтесь равенством \(T = \sum_{k=1}^n \sum_{j=1}^n \M(T)_{j,k} P_{j,k}\), чтобы показать, что \(\tau(T) = \tr T\).
