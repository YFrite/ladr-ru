Теорема 6.32 процесс ортогонализации Грама — Шмидта.

Пусть \(v_1, \dots, v_m\) — линейно независимая система векторов в пространстве \(V{}\). Положим \(f_1 = v_1\). Для \(k = 2, \dots, m\) определим векторы \(f_k\) по индукции формулой
\begin{equation*} f_k = v_k - \frac{\langle v_k, f_1 \rangle }{\lVert f_1 \rVert ^2} f_1 - \dots - \frac{\langle v_k, f_{k-1} \rangle }{\lVert f_{k-1} \rVert ^2} f_{k-1}. \end{equation*}
🔗
Для каждого \(k = 1, \ldots, m\) положим \(e_k = \dfrac{f_k}{\lVert f_k \rVert }\). Тогда \(e_1, \dots, e_m\) — ортонормированная система векторов в пространстве \(V\), причём
\begin{equation*} \Span (v_1, \dots, v_k) = \Span (e_1, \dots, e_k) \end{equation*}
для каждого \(k = 1, \dots, m\).
