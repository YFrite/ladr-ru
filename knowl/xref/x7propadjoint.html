Теорема 7.5 свойства сопряжения.

Предположим, \(T \in \Lc(V{}, W)\). Тогда
  1. \((S + T)^* = S^* + T^*\) для всех \(S\in \Lc(V{}, W)\);
    🔗
    🔗
  2. \((\lambda T)^* = \bar{\lambda} T^*\) для всех \(\lambda \in \F{}\);
    🔗
    🔗
  3. \(( T^* )^* = T\text{;}\)
    🔗
    🔗
  4. \((ST)^* = T^* S^*\) для всех \(S \in \Lc(W{}, U)\) (здесь \(U\) — конечномерное пространство со скалярным произведением над \(\F{}\));
    🔗
    🔗
  5. \(I^* = I\), где \(I\) — тождественный оператор на \(V\);
    🔗
    🔗
  6. если \(T\) обратимо, то обратимо \(T^*\) и \(( T^* )^{-1} = ( T^{-1} )^*{}\).
    🔗
    🔗
🔗
