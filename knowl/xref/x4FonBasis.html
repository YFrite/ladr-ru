Пример 6.29 ортонормированный базис пространства \(\F{4}\).

Как упоминалось выше, стандартный базис – это ортонормированный базис \(\FF{4}\). Сейчас мы покажем, что
\begin{equation*} ( \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2} ), ( \tfrac{1}{2}, \tfrac{1}{2}, -\tfrac{1}{2}, -\tfrac{1}{2} ), ( \tfrac{1}{2}, -\tfrac{1}{2}, -\tfrac{1}{2}, \tfrac{1}{2} ), ( -\tfrac{1}{2}, \tfrac{1}{2}, -\tfrac{1}{2}, \tfrac{1}{2} ) \end{equation*}
также является ортонормированным базисом \(\FF{4}\).
🔗
У нас есть
\begin{equation*} \lVert ( \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2} ) \rVert = \sqrt{ \tfrac{1}{2^2} + \tfrac{1}{2^2} + \tfrac{1}{2^2}+ \tfrac{1}{2^2} } = 1. \end{equation*}
🔗
Аналогично, остальные три вектора в списке выше также имеют норму \(1\).
🔗
Обратите внимание, что
\begin{equation*} \langle ( \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2}, \tfrac{1}{2} ), ( \tfrac{1}{2}, \tfrac{1}{2}, -\tfrac{1}{2}, -\tfrac{1}{2} ) \rangle = \tfrac{1}{2} \cdot \tfrac{1}{2} + \tfrac{1}{2} \cdot \tfrac{1}{2} + \tfrac{1}{2} \cdot ( -\tfrac{1}{2} ) + \tfrac{1}{2} \cdot ( -\tfrac{1}{2} ) = 0. \end{equation*}
🔗
Аналогично, скалярное произведение любых двух различных векторов в приведенном выше списке также равно \(0\).
🔗
Таким образом, приведенный выше список является ортонормированным. Поскольку у нас есть ортонормированный список длины четыре в четырехмерном векторном пространстве \(\FF{4}\), этот список является ортонормированным базисом \(\F{4}\) (по теореме 6.28).
