Пример 3.113 двойственный базис к стандартному базису пространства \(\F{n}\).

Пусть \(n\) — целое положительное число. При \(1 \le j \le n\) определим \(\phi_j\) как линейный функционал на \(\F{n}\), выделяющий координату с номером \(j^\nth\) вектора из \(\FF{n}\). Таким образом,
\begin{equation*} \phi_j(x_1, \dots, x_n) = x_j \end{equation*}
для каждого \((x_1, \dots, x_n) \in \FF{n}\).
🔗
Пусть \(e_1, \dots, e_n\) — стандартный базис пространства \(\FF{n}\). Тогда
\begin{equation*} \phi_j(e_k) = \begin{cases}1 \amp \text{ если } k = j,\\ 0 \amp \text{ если } k \ne j. \end{cases} \end{equation*}
🔗
Следовательно, \(\phi_1, \dots, \phi_n\) — базис, двойственный к стандартному базису \(e_1, \dots, e_n\) пространства \(\FF{n}\).
