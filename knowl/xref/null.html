Пример 3.12 нуль-пространство.

  1. Если \(T\) — нулевое отображение \(V\) в \(W{}\), то есть \(Tv = 0\) для каждого \(v \in V{}\), то \(\ker T = V{}\).
    🔗
    🔗
  2. Предположим, \(\phi \in \Lc( \CC3, \C{} )\) определяется \(\phi(z_1, z_2, z_3) = z_1 + 2z_2 + 3z_3\). Тогда \(\ker \phi\) равно \(\{ (z_1, z_2, z_3) \in \C3: z_1 + 2z_2 + 3z_3 = 0 \}\), которое является подпространством области определения \(\phi\). Вскоре мы увидим, что нуль-пространство каждого линейного отображения является подпространством его области определения.
    🔗
    🔗
  3. Предположим, что \(D\in \Lc\bigl(\P(\R{})\bigr)\) — отображение дифференцирования, определенное \(Dp = p'\!\). Единственные функции, производная которых равна нулю, — это постоянные функции. Таким образом, нуль-пространство \(D\) равно множеству постоянных функций.
    🔗
    🔗
  4. Предположим, что \(T\in \Lc\bigl(\P(\R{})\bigr)\) — это умножение на отображение \(x^2\), определенное \((Tp)(x) = x^2 p(x)\). Единственный многочлен \(p\), такой что \(x^2 p(x) = 0\) для всех \(x \in \R{}\), — это многочлен \(0\). Таким образом, \(\ker T = \{ 0 \}\).
    🔗
    🔗
  5. Предположим, что \(T\in \Lc( \F{\infty} )\) — сдвиг назад, определяемый формулой
    \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
    Тогда \(T(x_1, x_2, x_3, \dots)\) равно \(0\) тогда и только тогда, когда все числа \(x_2, x_3, \dots\) равны \(0\). Таким образом, \(\ker T = \{ (a, 0, 0, \dots): a \in \F{} \}\).
    🔗
    🔗
