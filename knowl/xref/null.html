Пример 3.12 нуль-пространство.

  1. Если \(T\) — нулевое отображение из \(V\) в \(W{}\), то есть \(Tv = 0\) для каждого \(v \in V{}\), то \(\ker T = V{}\).
    🔗
    🔗
  2. Пусть отображение \(\phi \in \Lc( \CC3, \C{} )\) определено формулой \(\phi(z_1, z_2, z_3) = z_1 + 2z_2 + 3z_3\). Тогда \(\ker \phi\) равно \(\{ (z_1, z_2, z_3) \in \C3: z_1 + 2z_2 + 3z_3 = 0 \}\), что является подпространством области определения отображения \(\phi\). Вскоре мы увидим, что нуль-пространство каждого линейного отображения является подпространством его области определения.
    🔗
    🔗
  3. Пусть \(D\in \Lc\bigl(\P(\R{})\bigr)\) — отображение дифференцирования, определённое формулой \(Dp = p'\!\). Единственные функции, производная которых равна нулевой функции, — это постоянные функции. Следовательно, нуль-пространство отображения \(D\) совпадает с множеством постоянных функций.
    🔗
    🔗
  4. Пусть \(T\in \Lc\bigl(\P(\R{})\bigr)\) — отображение умножения на \(x^2\), определённое формулой \((Tp)(x) = x^2 p(x)\). Единственный многочлен \(p\), для которого \(x^2 p(x) = 0\) при всех \(x \in \R{}\), — это нулевой многочлен \(0\). Следовательно, \(\ker T = \{ 0 \}\).
    🔗
    🔗
  5. Пусть \(T\in \Lc( \F{\infty} )\) — обратный сдвиг, определённый формулой
    \begin{equation*} T(x_1, x_2, x_3, \dots) = (x_2, x_3, \dots). \end{equation*}
    Тогда \(T(x_1, x_2, x_3, \dots)\) равно \(0\) в том и только том случае, когда все числа \(x_2, x_3, \dots\) равны \(0\). Следовательно, \(\ker T = \{ (a, 0, 0, \dots): a \in \F{} \}\).
    🔗
    🔗
