Теорема 6.57 свойства ортогонального проектора \(P_{U}\).

Пусть \(U\) — конечномерное подпространство пространства \(V{}\). Тогда
  1. \(P_{U} \in \Lc(V)\text{;}\)
    🔗
    🔗
  2. \(P_{U} u = u\) для каждого \(u \in U\);
    🔗
    🔗
  3. \(P_{U} w = 0\) для каждого \(w \in U^\perp\);
    🔗
    🔗
  4. \(\ran P_{U} = U\text{;}\)
    🔗
    🔗
  5. \(\ker P_{U} = U^\perp\text{;}\)
    🔗
    🔗
  6. \(v - P_{U} v \in U^\perp\) для каждого \(v \in V\);
    🔗
    🔗
  7. \({P_{U}}^{2} = P_{U}\text{;}\)
    🔗
    🔗
  8. \(\|P_{U} v\| \le \|v\|\) для каждого \(v \in V\);
    🔗
    🔗
  9. если \(e_1, \dots, e_m\) — ортонормированный базис подпространства \(U\) и \(v \in V{}\), то
    \begin{equation*} P_{U} v = \langle v, e_1 \rangle e_1 + \dots + \langle v, e_m \rangle e_m. \end{equation*}
    🔗
    🔗
🔗
