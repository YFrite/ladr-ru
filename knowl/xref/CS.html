Пример 6.16 неравенство Коши — Буняковского — Шварца.

  1. Если \(x_1, \ldots, x_n, y_1, \ldots, y_n \in \R{}\), то множество
    \begin{equation*} ( x_1 y_1 + \cdots + x_n y_n)^2 \le ( {x_1}^{2} + \cdots + {x_n}^{2} ) ( {y_1}^{2} + \cdots + {y_n}^{2} ), \end{equation*}
    что следует из применения неравенства Коши — Буняковского — Шварца к векторам \((x_1, \ldots, x_n), (y_1, \ldots, y_n) \in \RR n\) со стандартным евклидовым скалярным произведением.

    🔗
  2. Если \(f, g\) — непрерывные вещественнозначные функции на отрезке \([-1, 1]\), то
    \begin{equation*} \left\lvert \int_{-1}^1 fg \right\rvert ^{2} \le \left( \int_{-1}^1 f^2 \right) \left( \int_{-1}^1 g^2 \right), \end{equation*}
    что следует из применения неравенства Коши — Буняковского — Шварца к пространству из Примера 6.3(c).
