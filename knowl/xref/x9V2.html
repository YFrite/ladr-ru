Теорема 9.17 \(V^{(2)} = V^{(2)}_{\text{sym}} \oplus V^{(2)}_{\text{alt}}\).

Множества \(V^{(2)}_{\text{ sym } }\) и \(V^{(2)}_{\text{ alt } }\) являются подпространствами \(V^{(2)}\). Кроме того,
\begin{equation*} V^{(2)} = V^{(2)}_{\text{ sym } } \oplus V^{(2)}_{\text{ alt } }. \end{equation*}
