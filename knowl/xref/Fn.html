Пример 2.8 список, порождающий \(\F{n}\).

Пусть \(n\) — целое положительное число. Покажем, что список
\begin{equation*} (1, 0, \dots, 0), (0, 1, 0, \dots, 0), \dots, (0, \dots, 0, 1) \end{equation*}
порождает пространство \(\FF{n}\). Здесь \(k^\nth\)-й вектор списка имеет \(1\) на \(k^\nth\)-м месте и \(0\) на всех остальных местах.
🔗
Действительно, пусть \((x_1, \dots, x_n) \in \FF{n}\). Тогда
\begin{equation*} (x_1, \dots, x_n) = x_1 (1, 0, \dots, 0) + x_2 (0, 1, 0, \dots, 0) + \dots + x_n (0, \dots, 0, 1). \end{equation*}
🔗
Следовательно, \((x_1, \dots, x_n) \in \Span \bigl((1, 0, \dots, 0), (0, 1, 0, \dots, 0), \dots, (0, \dots, 0, 1)\bigr)\), что и требовалось доказать.
