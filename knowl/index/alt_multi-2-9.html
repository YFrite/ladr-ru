Определение 9.27 знакопеременные формы, \(V^{(m)}_{alt}\).

Предположим, что \(m\) — целое положительное число.
  1. \(m\)-линейная форма \(\alpha\) на \(V\) называется кососимметрической (знакопеременной), если \(\alpha (v_1, \ldots, v_m) = 0\) всякий раз, когда \(v_1, \ldots, v_m\) — список векторов из \(V\), в котором \(v_j = v_k\) для некоторых двух различных значений \(j\) и \(k\) из \(\{ 1, \ldots, m \}\).
    🔗
    🔗
  2. \(V^{(m)}_{\text{ alt } } = \{ \alpha \in V^{(m)}: \alpha \text{ — кососимметрическая \(m\)-линейная форма на } V \}\text{.}\)
