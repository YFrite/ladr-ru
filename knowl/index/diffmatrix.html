Пример 3.33 матрица оператора дифференцирования из \(\P_3(\R)\) в \(\P_2(\R)\).

Предположим, что \(D \in \Lc\bigl(\P{}_3(\R{}), \P{}_2(\R{}) \bigr)\) — отображение дифференцирования, определенное \(Dp = p'\!\). Поскольку \({(x^n)}' = nx^{n-1}\!\), матрица \(D\) относительно стандартных базисов представляет собой матрицу \(3\) на \(4\) ниже:
\begin{equation*} \M(D) = \begin{pmatrix}0\amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 0 \amp 3 \\ \end{pmatrix} . \end{equation*}
