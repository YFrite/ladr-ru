Пример 5.72 операторы частного дифференцирования коммутируют.

Пусть \(m\) — целое неотрицательное число. Обозначим через \(\P\!_m{}(\CC2, \C{})\) комплексное векторное пространство многочленов (с коэффициентами из \(\C{}\)) от двух переменных степени не выше \(m\) с обычными операциями сложения и умножения на скаляр для \(\C{}\)-значных функций. Таким образом, элементами пространства \(\P\!_m{}(\CC2, \C{})\) являются функции \(p\) из \(\C2\) в \(\C{}\) вида
\begin{equation} p(w,z) = \sum_{j+k \le m} a_{j,k} w^j z^k\!,\tag{5.73} \end{equation}
где индексы \(j\) и \(k\) пробегают все целые неотрицательные значения, удовлетворяющие условию \(j + k \le m\), каждый коэффициент \(a_{j,k}\) принадлежит \(\C{}\), а \(w^j z^k\) обозначает функцию на \(\C2\), заданную правилом \((w, z) \mapsto w^j z^k\!\).
🔗
Зададим операторы \(D_w, D_z \in \Lc( \P\!_m{}(\CC2, \C{}) )\) формулами
\begin{equation*} D_w p = \frac{ \partial p}{\partial w} = \sum_{j+k \le m} j a_{j,k} w^{j-1} z^k \andd D_z p = \frac{ \partial p}{\partial z} = \sum_{j+k \le m} k a_{j,k} w^j z^{k-1}\!, \end{equation*}
где многочлен \(p\) имеет вид (5.73). Операторы \(D_w\) и \(D_z\) называются операторами частного дифференцирования, поскольку каждый из них дифференцирует функцию по одной из переменных, считая другую переменную постоянной.
🔗
Операторы \(D_w\) и \(D_z\) коммутируют, так как для любого многочлена \(p\) вида (5.73) имеем
\begin{equation*} (D_w D_z)p = \sum_{j+k \le m} j k a_{j,k} w^{j-1} z^{k-1} = (D_z D_w)p. \end{equation*}
🔗
Равенство \(D_w D_z = D_z D_w\) на пространстве \(\P\!_m{}(\CC2, \C{})\) иллюстрирует более общий факт: для достаточно гладких функций результат смешанного частного дифференцирования не зависит от порядка дифференцирования.
