Определение 9.14 кососимметрическая (знакопеременная) билинейная форма, \(V^{(2)}_{\text{alt}}\).

Билинейная форма \(\alpha \in V^{(2)}\) называется кососимметрической (или знакопеременной), если
\begin{equation*} \alpha (v,v) = 0 \end{equation*}
для всех \(v \in V{}\). Множество всех кососимметрических билинейных форм на \(V\) обозначается через \(V^{(2)}_{\text{ alt } }\).
