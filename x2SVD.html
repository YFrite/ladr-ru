    Раздел 7.5 Сингулярное разложение

    Подраздел 7.5.1 Сингулярные числа

    В этом разделе нам понадобится следующий результат.
    🔗

    Теорема 7.64 свойства \(T^*T\).

    Предположим, \(T \in \Lc(V{}, W)\). Тогда
    1. \(T^* T\) — положительный оператор на \(V\);
      🔗
      🔗
    2. \(\ker T^*T = \ker T\text{;}\)
      🔗
      🔗
    3. \(\ran T^*T = \ran T^*\text{;}\)
      🔗
      🔗
    4. \(\dim \ran T = \dim \ran T^* = \dim \ran T^* T{}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    1. У нас есть
      \begin{equation*} ( T^* T )^* = T^* ( T^* )^* = T^* T{}. \end{equation*}
      Таким образом, \(T^* T\) самосопряжено. Если \(v \in V{}\), то
      \begin{equation*} \langle ( T^*T )v , v \rangle = \langle T^*(Tv), v \rangle = \langle Tv, Tv \rangle = \|Tv\|^2 \ge 0. \end{equation*}
      Таким образом, \(T^* T\) — положительный оператор.
      🔗
      🔗
    2. Сначала предположим, что \(v \in \ker T^*T{}\). Тогда
      \begin{equation*} \lVert Tv \rVert ^2 = \langle Tv, Tv \rangle = \langle T^*Tv, v \rangle = \langle 0, v \rangle = 0. \end{equation*}
      Таким образом, \(Tv = 0\), доказывая, что \(\ker T^*T \subset \ker T{}\). Включение в другую сторону понятно, ведь если \(v \in V\) и \(Tv = 0\), то \(T^*Tv = 0\). Таким образом, \(\ker T^*T = \ker T\) завершает доказательство (b).
      🔗
      🔗
    3. Мы уже знаем из (а), что \(T^*T\) самосопряжено. Таким образом
      \begin{equation*} \ran T^* T = ( \ker T^* T )^\perp = (\ker T)^\perp = \ran T^*{}, \end{equation*}
      где первое и последнее равенства взяты из теоремы 7.6, а второе равенство - из (b).
      🔗
      🔗
    4. Чтобы проверить первое уравнение в (d), обратите внимание, что
      \begin{equation*} \dim \ran T = \dim ( \ker T^* )^\perp = \dim W - \dim \ker T^* = \dim \ran T^*{}, \end{equation*}
      где первое равенство вытекает из Теоремы 7.6(d), второе равенство вытекает из Теоремы 6.51, а последнее равенство вытекает из фундаментальной теоремы о линейных отображениях Теорема 3.21. Равенство \(\dim \ran T^* = \dim \ran T^* T\) следует из (в).
      🔗
      🔗
    🔗
    🔗
    Собственные значения оператора кое-что говорят нам о поведении оператора. Еще один набор чисел, называемый сингулярными числами, также полезен. Собственные пространства и обозначение \(E\) (используемое в примерах) были определены в Определении 5.52.
    🔗

    Определение 7.65 сингулярные числа.

    Предположим, \(T \in \Lc(V{}, W)\). сингулярные числа \(T\) — это неотрицательные квадратные корни из собственных значений \(T^* T{}\), перечисленных в порядке убывания, каждое из которых включает столько раз, сколько размерность соответствующего собственного пространства \(T^*T{}\).
    🔗
    🔗

    Пример 7.66 сингулярные числа оператора на \(\F4\).

    Определите \(T \in \Lc( \F{4} )\) через \(T(z_1, z_2, z_3, z_4) = (0, 3 z_1, 2 z_2, -3z_4)\). Расчет показывает, что
    \begin{equation*} T^*T(z_1, z_2, z_3, z_4) = (9 z_1, 4z_2, 0, 9z_4), \end{equation*}
    как вы должны проверить. Таким образом, стандартный базис \(\F4\) диагонализует \(T^*T\), и мы видим, что собственными значениями \(T^* T\) являются \(9\), \(4\) и \(0\). Кроме того, размеры собственных пространств, соответствующих собственным значениям, равны
    \begin{equation*} \dim E( 9, T^* T ) = 2 \andd \dim E( 4, T^* T ) = 1 \andd \dim E( 0, T^*T ) = 1. \end{equation*}
    🔗
    Извлекая неотрицательные квадратные корни из этих собственных значений \(T^*T\) и используя информацию о размерах, полученную выше, мы приходим к выводу, что сингулярные числа \(T\) — это \(3, 3, 2, 0\).
    🔗
    Единственными собственными значениями \(T\) являются \(-3\) и \(0\). Таким образом, в этом случае набор собственных значений не принял число \(2\), которое появляется в определении (и, следовательно, в поведении) \(T\), но список сингулярных чисел действительно включает \(2\).
    🔗
    🔗

    Пример 7.67 сингулярные числа линейного отображения из \(\F4\) в \(\F3\).

    Предположим, что \(T \in \Lc( \F4, \F3 )\) имеет матрицу (относительно стандартных базисов)
    \begin{equation*} \begin{pmatrix}0 \amp 0 \amp 0 \amp -5 \\ 0 \amp 0 \amp 0 \amp 0\\ 1 \amp 1 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
    🔗
    Вы можете убедиться, что матрица \(T^* T\) равна
    \begin{equation*} \begin{pmatrix}1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 0\amp 0\\ 0 \amp 0 \amp 0 \amp 25 \end{pmatrix} \end{equation*}
    и что собственные значения оператора \(T^*T\) суть \(25\), \(2\), \(0\), причем \(\dim E( 25, T^* T ) = 1\), \(\dim E( 2, T^* T ) = 1\) и \(\dim E( 0, T^*T ) = 2\). Таким образом, сингулярными числами \(T\) являются \(5, \sqrt{2}, 0, 0\).
    🔗
    🔗
    См. Упражнение 7.5.2.2 для описания положительных сингулярных чисел.
    🔗

    Теорема 7.68 роль положительных сингулярных чисел.

    Предположим, что \(T \in \Lc(V{}, W)\). Тогда
    1. \(T\) инъективен. \(\iff 0\) не является сингулярным числом \(T\);
      🔗
      🔗
    2. количество положительных сингулярных чисел \(T\) равно \(\dim \ran T\);
      🔗
      🔗
    3. \(T\) — сюръективное число \(\iff\) положительных сингулярных чисел \(T\) равно \(\dim W{}\).
      🔗
      🔗
    🔗
    🔗

    Доказательство.
    Линейное отображение \(T\) инъективно тогда и только тогда, когда \(\ker T = \{ 0 \}\), что происходит тогда и только тогда, когда \(\ker T^*T = \{ 0 \}\) [по Теореме 7.64(b)] , что происходит тогда и только тогда, когда \(0\) не является собственным значением \(T^*T\), что происходит тогда и только тогда, когда \(0\) не является сингулярным числом \(T\), что завершает доказательство (a).
    🔗
    Спектральная теорема, примененная к \(T^* T\), показывает, что \(\dim \ran T^*T\) равно количеству положительных собственных значений \(T^*T\) (с учетом повторений). Таким образом, из теоремы 7.64(d) следует, что \(\dim \ran T\) равно числу положительных сингулярных чисел \(T\), что доказывает (b).
    🔗
    Используйте (b) и теорему 2.39, чтобы показать, что (c) выполняется.
    🔗
    🔗

    Теорема 7.69 изометрии характеризуются тем, что все их сингулярные числа равны \(1\).

    Предположим, что \(S \in \Lc(V{}, W)\). Тогда
    🔗
    \(S\) — изометрия \(\iff\), все сингулярные числа \(S\) равны \(1\).
    🔗
    🔗
    🔗

    Доказательство.
    У нас есть
    \begin{align*} S \text{— изометрия } \amp \iff S^* S = I\\ \amp \iff \text{ все собственные значения } S^* S \text{ равны } 1 \\ \amp \iff \text{ все сингулярные числа } S \text{ равны } 1, \end{align*}
    где первая эквивалентность вытекает из Теоремы 7.49, а вторая эквивалентность вытекает из спектральной теоремы (Теорема 7.29 или Теорема 7.31), примененной к самосопряженному оператору \(S^* S\).
    🔗
    🔗
    🔗

    Подраздел 7.5.2 Сингулярное разложение для линейных отображений и матриц

    Примечание
    Сингулярное разложение полезно в вычислительной линейной алгебре, поскольку существуют хорошие методы аппроксимации собственных значений и собственных векторов положительных операторов, таких как \(T^*T\), собственные значения и собственные векторы которых приводят к сингулярному разложению.
    🔗
    Следующий результат показывает, что каждое линейное отображение из \(V\) в \(W\) имеет удивительно чистое описание в терминах сингулярных чисел и ортонормированных списков в \(V\) и \(W{}\). В следующем разделе мы увидим несколько важных применений сингулярного разложения (часто называемого SVD).
    🔗

    Теорема 7.70 сингулярное разложение.

    Предположим, что \(T \in \Lc(V{}, W)\) и положительные сингулярные числа \(T\) равны \(s_1, \dots, s_m\). Тогда существуют ортонормированные списки \(e_1, \dots, e_m\) в \(V\) и \(f_1, \dots, f_m\) в \(W\) такие, что
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m\tag{7.71} \end{equation}
    для каждого \(v \in V{}\).
    🔗
    🔗

    Доказательство.
    Пусть \(s_1, \ldots, s_n\) обозначает сингулярные числа \(T\) (таким образом, \(n = \dim V\)). Поскольку \(T^*T\) является положительным оператором (см. Теорему 7.64(a)] , из спектральной теоремы следует, что существует ортонормированный базис \(e_1, \ldots, e_n\) оператора \(V\) с
    \begin{equation} T^*T e_k = {s_k}^{2} e_k\tag{7.72} \end{equation}
    для каждого \(k = 1, \ldots, n\).
    🔗
    Пусть для каждого \(k = 1, \ldots, m\)
    \begin{equation} f_k = \frac{Te_k}{s_k}.\tag{7.73} \end{equation}
    🔗
    Если \(j, k \in \{ 1, \ldots, m \}\), то
    \begin{equation*} \langle f_j, f_k \rangle = \frac{1}{s_j s_k} \langle Te_j, Te_k \rangle = \frac{1}{s_j s_k} \langle e_j, T^*T e_k \rangle = \frac{s_k}{s_j} \langle e_j, e_k \rangle = \begin{cases}0 \amp \text{ если } j \ne k ,\\ 1 \amp \text{ если } j = k. \end{cases} \end{equation*}
    🔗
    Таким образом, \(f_1, \ldots, f_m\) — ортонормированный список в \(W{}\).
    🔗
    Если \(k \in \{ 1, \ldots, n \}\) и \(k > m\), то \(s_k = 0\) и, следовательно, \(T^*T e_k = 0\) (по (7.72)), откуда следует, что \(Te_k = 0\) [по Теореме 7.64(b)] .
    🔗
    Предположим, \(v \in V{}\). Тогда
    \begin{align*} Tv \amp = T( \langle v, e_1 \rangle e_1 + \cdots + \langle v, e_n \rangle e_n )\\ \amp = \langle v, e_1 \rangle Te_1 + \cdots + \langle v, e_m \rangle Te_m\\ \amp = s_1 \langle v, e_1 \rangle f_1 + \cdots + s_m \langle v, e_m \rangle f_m\text{,} \end{align*}
    где последний индекс в первой строке переключился с \(n\) на \(m\) во второй строке, потому что \(Te_k = 0\) если \(k > m\) (как отмечено в пункте выше), а третья строка следует из (7.73). Уравнение выше и есть наш желаемый результат.
    🔗
    🔗
    Предположим, \(T \in \Lc(V{}, W)\), что положительными сингулярными числами \(T\) являются \(s_1, \ldots, s_m\), а \(e_1, \ldots, e_m\) и \(f_1, \ldots, f_m\) такие же, как в сингулярном разложении Теорема 7.70. Ортонормированный список \(e_1, \ldots, e_m\) может быть расширен до ортонормированного базиса \(e_1, \ldots, e_{\dim V}\) из \(V\), а ортонормированный список \(f_1, \ldots, f_m\) может быть расширен до ортонормированного базиса \(f_1, \ldots, f_{\dim W}\) из \(W{}\). Формула (7.71) показывает, что
    \begin{equation*} Te_k = \begin{cases}s_k f_k \amp \text{ если } 1 \le k \le m,\\ 0 \amp \text{ если } m \lt k \le \dim V{}. \end{cases} \end{equation*}
    🔗
    Таким образом, матрица \(T\) относительно ортонормированных базисов \((e_1, \ldots, e_{\dim V})\) и \((f_1, \ldots, f_{\dim W})\) имеет простой вид
    \begin{equation*} \M( T, (e_1, \ldots, e_{\dim V}), (f_1, \ldots, f_{\dim W}) )_{j,k} = \begin{cases}s_k \amp \text{ если } 1 \le j = k \le m, \\ 0 \amp \text{ иначе } . \end{cases} \end{equation*}
    🔗
    Если \(\dim V = \dim W\) (как это бывает, например, если \(W = V\)), то матрица, описанная в пункте выше, является диагональной матрицей. Если мы расширим определение диагональной матрицы следующим образом и применим его к матрицам, которые не обязательно являются квадратными, то мы докажем замечательный результат: каждое линейное отображение из \(V\) в \(W\) имеет диагональную матрицу относительно соответствующих ортонормированных базисов.
    🔗

    Определение 7.74 диагональная матрица.

    Матрица \(A\) размером \(M\) на \(N\) называется диагональной матрицей, если все элементы матрицы являются \(0\), за исключением, возможно, \(A_{k,k}\) для \(k = 1, \ldots, \min \{ M, N \}\).
    🔗
    🔗
    В таблице ниже спектральная теорема ( Теорема 7.29 и Теорема 7.31) сравнивается с сингулярным разложением Теорема 7.70.
    🔗
    спектральная теорема Сингулярное разложение
    описывает только самосопряженные операторы (когда \(\F{} = \R{}\)) или нормальные операторы (когда \(\F{} = \C{}\)) описывает произвольные линейные отображения из пространства со скалярным произведением в возможно другое пространство со скалярным произведением
    создает единый ортонормированный базис создает два ортонормированных списка, один для пространства области определения и один для пространства образов, которые не обязательно совпадают, даже если пространство образов равно пространству области определения.
    разные доказательства в зависимости от того, \(\F{} = \R{}\) или \(\F{}=\C{}\) одно и то же доказательство работает независимо от того, \(\F{} = \R{}\) или \(\F{}=\C{}\)
    Сингулярное разложение дает нам новый способ понять сопряженное и обратное линейному отображению. В частности, следующий результат показывает, что, учитывая сингулярное разложение линейного отображения \(T \in \Lc(V{},W)\), мы можем получить сопряженное к \(T\), просто меняя местами роли \(e\) и \(f\) (см. (7.77)). Аналогичным образом мы можем получить псевдообратное \(T^\dagger\) (см. Определение 6.68) для \(T\), поменяв местами роли \(e\) и \(f\) и заменив каждое положительное сингулярное число \(s_k\) \(T\) на \(1/s_k\) (см. (7.78)).
    🔗
    Напомним, что псевдообратный \(T^\dagger\) в (7.78) ниже равен обратному \(T^{-1}\), если \(T\) обратим [см. Теорему 6.69(a)] .
    🔗

    Теорема 7.75 сингулярное разложение сопряженного и псевдообратного.

    Предположим, что \(T \in \Lc(V{}, W)\) и положительные сингулярные числа \(T\) равны \(s_1, \dots, s_m\). Предположим, что \(e_1, \dots, e_m\) и \(f_1, \dots, f_m\) — ортонормированные списки в \(V\) и \(W\) такие, что
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m\tag{7.76} \end{equation}
    для каждого \(v \in V{}\). Тогда
    \begin{equation} T^*w = s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m\tag{7.77} \end{equation}
    и
    \begin{equation} T^\dagger w = \frac{\langle w, f_1 \rangle }{s_1} e_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} e_m\tag{7.78} \end{equation}
    для каждого \(w \in W{}\).
    🔗
    🔗

    Доказательство.
    Если \(v \in V\) и \(w \in W\), то
    \begin{align*} \langle Tv,w \rangle \amp = \langle s_1 \langle v, e_1 \rangle f_1 + \dots + s_m \langle v, e_m \rangle f_m, w \rangle\\ \amp = s_1 \langle v, e_1 \rangle \langle f_1,w \rangle + \dots + s_m \langle v, e_m \rangle \langle f_m, w \rangle\\ \amp = \langle v, s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m \rangle \text{.} \end{align*}
    🔗
    Это означает, что
    \begin{equation*} T^*w = s_1 \langle w, f_1 \rangle e_1 + \dots + s_m \langle w, f_m \rangle e_m, \end{equation*}
    🔗
    доказывая (7.77).
    🔗
    Чтобы доказать (7.78), предположим \(w \in W{}\). Пусть
    \begin{equation*} v = \frac{\langle w, f_1 \rangle }{s_1} e_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} e_m. \end{equation*}
    🔗
    Примените \(T\) к обеим частям приведенного выше уравнения, получив
    \begin{align*} Tv \amp = \frac{\langle w, f_1 \rangle }{s_1} Te_1 + \dots + \frac{\langle w, f_m \rangle }{s_m} Te_m\\ \amp = \langle w, f_1 \rangle f_1 + \dots + \langle w, f_m \rangle f_m\\ \amp = P_{\ran T} w\text{,} \end{align*}
    где вторая строка верна, потому что (7.76) подразумевает, что \(Te_k = s_k f_k\), если \(k = 1, \ldots, m\), а последняя строка выше верна, потому что (7.76) подразумевает, что \(f_1, \ldots, f_m\) порождает \(\ran T\) и, следовательно, является ортонормированным базисом \(\ran T\) [и, следовательно, применима теорема 6.57(i)] . Уравнение выше, наблюдение, что \(v \in (\ker T)^\perp\) [см. Упражнение 7.5.2.8(b)] , и определение \(T^\dagger w\) (см. Определение 6.68) показывают, что \(v = T^\dagger w\), доказывая (7.78).
    🔗
    🔗

    Пример 7.79 найти сингулярное разложение.

    Определите \(T \in \Lc( \F4, \F3 )\) через \(T(x_1, x_2, x_3, x_4) = (-5x_4, 0, x_1 + x_2)\). Мы хотим найти сингулярное разложение \(T{}\). Матрица \(T\) (относительно стандартных базисов) имеет вид
    \begin{equation*} \begin{pmatrix}0 \amp 0 \amp 0 \amp -5 \\ 0 \amp 0 \amp 0 \amp 0\\ 1 \amp 1 \amp 0 \amp 0 \end{pmatrix} . \end{equation*}
    🔗
    Таким образом, как обсуждалось в Примере 7.67, матрица \(T^*T\) равна
    \begin{equation*} \begin{pmatrix}1 \amp 1 \amp 0 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0\\ 0 \amp 0 \amp 0\amp 0\\ 0 \amp 0 \amp 0 \amp 25 \end{pmatrix} , \end{equation*}
    а положительные собственные значения \(T^*T\) — это \(25\), \(2\), причем \(\dim E( 25, T^* T ) = 1\) и \(\dim E( 2, T^* T ) = 1\). Следовательно, положительные сингулярные числа \(T\) — это \(5, \sqrt{2}\).
    🔗
    Таким образом, чтобы найти сингулярное разложение \(T\), мы должны найти ортонормированный список \(e_1, e_2\) в \(\F4\) и ортонормированный список \(f_1, f_2\) в \(\F3\) такие, что
    \begin{equation*} Tv = 5 \langle v, e_1 \rangle f_1 + \sqrt{2} \langle v, e_2 \rangle f_2 \end{equation*}
    для всех \(v \in \F4\).
    🔗
    Ортонормированным базисом \(E( 25, T^* T )\) является вектор \((0,0,0,1 )\); ортонормированным базисом \(E( 2, T^*T )\) является вектор \(( \frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}},0,0 )\). Таким образом, следуя доказательству теоремы 7.70, возьмем
    \begin{equation*} e_1 = (0,0,0,1) \andd e_2 = ( \frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}},0,0 ) \end{equation*}
    и
    \begin{equation*} f_1 = \frac{Te_1}{5} = (-1, 0, 0) \andd f_2 = \frac{Te_2}{\sqrt{2}} = (0, 0, 1). \end{equation*}
    🔗
    Затем, как и ожидалось, мы видим, что \(e_1, e_2\) — ортонормированный список в \(\F4\), \(f_1, f_2\) — ортонормированный список в \(\F3\) и
    \begin{equation*} Tv = 5 \langle v, e_1 \rangle f_1 + \sqrt{2} \langle v, e_2 \rangle f_2 \end{equation*}
    для всех \(v \in \F4\). Таким образом, мы нашли сингулярное разложение \(T{}\).
    🔗
    🔗

В частности, следующий результат дает факторизацию произвольной матрицы как произведения трех хороших матриц. Доказательство дает явное построение этих трех матриц в терминах сингулярного разложения.

    Теорема 7.80 матричный вариант СВД.

    Предположим, что \(A\) — матрица размера \(p\) на \(n\) ранга \(m\ge1\). Тогда существуют матрица \(B\) размером \(p\) на \(m\) с ортонормированными столбцами, диагональная матрица \(D\) размером \(m\) на \(m\) с положительными числами на диагонали и матрица \(C\) размером \(n\) на \(m\) с ортонормированными столбцами такие, что
    \begin{equation*} A = B D C^*{}. \end{equation*}
    🔗
    🔗

    Доказательство.
    Пусть \(\fun T {\F{n}} {\F{p}}\) — линейное отображение, матрица которого относительно стандартных базисов равна \(A\). Тогда \(\dim \ran T = m\) (по теореме 3.78). Пусть
    \begin{equation} Tv = s_1 \langle v, e_1 \rangle f_1 + \cdots + s_m \langle v, e_m \rangle f_m\tag{7.81} \end{equation}
    — сингулярное разложение \(T{}\). Пусть
    \begin{align*} B \amp = \text{ матрица \(p\times m\), столбцы которой — } f_1, \ldots, f_m,\\ D \amp = \text{ диагональная матрица \(m\times m\) с диагональными элементами } s_1, \ldots, s_m,\\ C \amp = \text{ матрица \(n\times m\), столбцы которой — } e_1, \ldots, e_m\text{.} \end{align*}
    🔗
    Обозначим через \(u_1, \ldots, u_m\) стандартный базис \(\FF{m}\). Если \(k \in \{ 1, \ldots, m \}\), то
    \begin{equation*} (AC - BD)u_k = Ae_k - B(s_k u_k) = s_k f_k - s_k f_k = 0. \end{equation*}
    🔗
    Таким образом, \(AC = B D\).
    🔗
    Умножьте обе части этого последнего уравнения на \(C^*\) (сопряженное транспонирование \(C\)) справа, чтобы получить
    \begin{equation*} ACC^* = B D C^*{}. \end{equation*}
    🔗
    Обратите внимание, что строки \(C^*\) являются комплексно-сопряженными числами \(e_1, \ldots, e_m\). Таким образом, если \(k \in \{ 1, \ldots, m \}\), то определение умножения матриц показывает, что \(C^*e_k = u_k\); отсюда \(CC^* e_k = e_k\). Таким образом \(ACC^*v = Av\) для всех \(v \in \Span(e_1, \dots, e_m)\).
    🔗
    Если \(v \in ( \Span(e_1, \ldots, e_m) )^\perp\), то \(Av = 0\) (как следует из (7.81)) и \(C^*v = 0\) (как следует из определения умножения матриц). Следовательно, \(ACC^*v = Av\) для всех \(v \in ( \Span(e_1, \dots, e_m) )^\perp\).
    🔗
    Поскольку \(ACC^*\) и \(A\) совпадают относительно \(\Span(e_1, \dots, e_m)\) и \(( \Span(e_1, \dots, e_m) )^\perp\), мы заключаем, что \(ACC^* = A\). Таким образом, отображаемое выше уравнение становится
    \begin{equation*} A = B D C^*{}, \end{equation*}
    по желанию.
    🔗
    🔗
    Обратите внимание, что матрица \(A\) в приведенном выше результате имеет элементы \(pn\). Для сравнения, приведенные выше матрицы \(B\), \(D\) и \(C\) имеют в общей сложности
    \begin{equation*} m(p + m + n) \end{equation*}
    элементы. Таким образом, если \(p\) и \(n\) — большие числа, а ранг \(m\) значительно меньше, чем \(p\) и \(n\), то количество элементов, которые необходимо сохранить в компьютере для представления \(A\), значительно меньше, чем \(pn\).
    🔗
